==========================================
效果设置
==========================================

从 :ref:`6F3A3C96-A0C9-440C-89B7-0DCC7EB0A5C5` 打开的各个效果设置画面。

主要用于更改各个效果的分配。

.. note::
    关于截图中使用的资源

   * 模型使用 `Kizuna AI <https://kizunaai.com/download/>`_
   * 效果使用 `Ray-MMD (1.5.2) <https://github.com/ray-cast/ray-mmd>`_

离屏
******************************************

.. image:: images/effect/offscreen.png

可以更改离屏效果的分配设置。

* 画面左侧显示项目内管理的离屏效果列表。
* 画面右侧显示所选离屏效果的详细信息。

  * 上部显示离屏效果的说明。
  * 下部显示已应用到离屏效果的模型或附件列表。

    * 点击显示文件名的按钮会显示文件对话框，可以更改分配的效果
    * 点击橡皮擦按钮可以解除分配
    * 灰色部分不可操作（例如离屏效果自身的模型或附件）

模型
******************************************

.. image:: images/effect/model.png

可以更改按模型材质单位分配的效果设置。

.. important::
    从 30.3.0 开始实现了 MME 中使用的模型效果分配信息设置文件 emd 格式的读写。

* 画面左侧显示项目内管理的模型或附件列表。

  * 画面左下方的「读取」用于加载 emd 格式的数据
  * 画面左下方的「保存」用于保存 emd 格式的数据

* 画面右侧显示分配给模型材质的效果列表。

  * 点击按钮部分会显示文件对话框，可以更改分配的效果
  * 点击橡皮擦按钮可以解除分配

参数
******************************************

显示路径、渲染目标列表。点击「重新加载效果」按钮可以重新加载所选模型或附件的效果。

.. hint::
    如果修改效果的源代码，系统会自动检测变更并重新加载，这种方式更简单。

    但不支持 ``include`` 的效果的自动检测，需要修改 ``include`` 方侧的效果
    （主要是扩展名为 ``conf`` 或 ``fxsub`` 的文件是 ``include`` 侧的效果）。

.. image:: images/effect/parameters.png

启用「启用参数调试」后，会显示分配给效果的参数内容。

.. image:: images/effect/render_target.png

渲染目标上方显示说明，下方以图像形式显示渲染目标的内容。

==========================================
模型编辑
==========================================

.. important::
    需要从菜单的「:ref:`5A6CDB09-18D8-4D55-9D35-6FEF0A0B62FF`」打开。同时需要从「:doc:`preference`」中勾选「:ref:`F517A3B9-3273-4FE3-BD1E-4EDA53843140`」。

    切换到模型编辑模式需要预先保存项目。此外，进入模型编辑模式后，在模型编辑期间，为保证编辑目标模型及项目的一致性，有以下限制：

   * 无法播放项目
   * 所有关键帧注册处理无效
   * 隐藏编辑目标以外的模型及配件
   * 无法切换编辑目标以外的模型
   * 模型的姿势设置为加载后的状态
   * 禁用物理运算
   * 网格隐藏时显示
   * 强制禁用「:ref:`D1BF8CFD-152D-4D1C-8B23-1FC6A4EBF391`」
   * 无法使用「:ref:`7BFC3B84-55EB-4E4B-A827-4E53401DC0AE`」

     * 截至 33.0，由于其他问题「:ref:`7F24495C-52C6-4659-A309-0E75CAB72D3B」也无法使用，但计划放宽此限制

    关闭模型编辑窗口后回到编辑前的状态。此时编辑后的模型会直接反映，
    同时编辑前模型数据的副本会以在模型名后添加切换至模型编辑模式的日期时间的形式保存为文件名。
    即使从编辑模式中退出应用程序（不包括崩溃导致的强制结束）也同样执行此操作。

模型编辑画面用于调整模型的参数或添加删除对象。

模型编辑面板按模型对象类型分为各选项卡，左侧为模型对象列表，右侧为参数编辑画面。

模型对象列表中名称左侧有用于显示屏蔽的复选框，✅ 状态时可在模型编辑模式下选择。
反之取消勾选时无法选择。合理利用此功能可以轻松选择特定的模型对象。

.. note::
    用于屏蔽的复选框在「变形」及「显示框」中不存在。

画面左下角的图标集可用于添加、删除及移动对象。

- 加号图标负责添加对象
- 减号图标负责删除对象

  - 仅可删除单个对象
  - 因此多选时禁用

- 上图标用于将对象向上移动

  - 对象位于最顶层时禁用
  - 多选时也禁用

- 下图标用于将对象向下移动

  - 对象位于最底层时禁用
  - 多选时也禁用

- 顶点和面面板没有图标集

参数编辑画面左上角齿轮图标显示的「可用操作」具有以下共同特点：

- 如果选择目标已被选中，则保持选中状态
- 取消选中状态时如果已经取消则保持取消状态
- 对特定对象执行选择操作时，先取消所有选中状态

  - 🎯（靶心）标记的对象为目标
  - 按住 Shift 键时，不取消选中状态，可以追加选择对象

选择多个模型对象时会切换到批量编辑画面，可批量编辑模型对象。

- 按索引顺序第一个模型对象的参数被设置

  - 可以选择参数设置来源的模型对象
  - 更改设置来源的模型对象时参数会被覆盖，请注意

- 批量编辑会应用表单上的所有参数。无法部分更改
- 无法批量更改名称、纹理、变形内的模型对象

操作
==========================================

相机
------------------------------------------

切换到相机模式。

选择 > 顶点
----------------------------------------------------------------------

设置为顶点的选择模式。

设置后顶点显示为蓝点，选中的顶点显示为红点。
选择标准根据顶点的原点坐标是否包含在选择范围内判断。

选择 > 面
----------------------------------------------------------------------

设置为面的选择模式。

设置后边显示为黑线，选中的面显示为红线。
选择标准根据面的中心坐标是否包含在选择范围内判断。

选择 > 材质
----------------------------------------------------------------------

设置为材质的选择模式。

选择标准根据材质的中心坐标是否包含在选择范围内判断。

选择 > 骨骼
----------------------------------------------------------------------

设置为骨骼的选择模式。

设置后包括不可见骨骼在内的所有骨骼都会显示，选中的骨骼显示为红点。
选择标准根据骨骼的原点坐标是否包含在选择范围内判断。

选择 > 刚体
----------------------------------------------------------------------

设置为刚体的选择模式。

选择后根据刚体的形状类型渲染，选中的刚体显示为红色。
选择标准根据刚体的原点坐标是否包含在选择范围内判断。

选择 > 关节
----------------------------------------------------------------------

设置为关节的选择模式。

选择后关节中心显示为黄色，选中的关节显示为红色。
选择标准根据关节的原点坐标是否包含在选择范围内判断。

创建父骨骼
------------------------------------------

以拖动骨骼的形式创建父骨骼。

拖动源的骨骼被设置为显示目标，拖动的骨骼被创建为父骨骼。
「:ref:`F644B967-20A9-4055-946B-A861FE72E929`」是与此相反的处理。

.. _F644B967-20A9-4055-946B-A861FE72E929:

创建显示目标骨骼
------------------------------------------

.. caution::
    由于内部处理原因，拖动过程中与「:ref:`D0D02D3E-5A3C-4B75-A806-4C95E0D1D42D`」同方向显示，但拖动结束后会反转并正确显示。

以拖动骨骼的形式创建显示目标骨骼。

拖动源的骨骼被设置为父骨骼，拖动的骨骼被创建为显示目标骨骼。
「:ref:`D0D02D3E-5A3C-4B75-A806-4C95E0D1D42D`」是与此相反的处理。

顶点权重绘制
==========================================

.. note::
    设置操作的「:ref:`69D2DE53-5A76-4F1F-AC22-2FF7CF621CE9」」后显示。

顶点权重绘制是一种可视化操作用来调整顶点与关联骨骼的权重分配的模式。
此时模型显示会切换到顶点权重绘制专用渲染。

* 红色部分为影响最强的区域
* 蓝色部分为影响最弱的区域
* 灰色部分为未映射权重的区域

绘制类型
----------------------------------------------------------------------

选择权重绘制使用的类型。

.. csv-table::

   类型,说明
   基础笔刷,使用「顶点类型」与「骨骼」指定的信息进行填充。
   喷枪,选择骨骼，仅对该骨骼的权重像喷枪一样增减。

顶点类型
----------------------------------------------------------------------

.. note::
    仅笔刷类型为基础笔刷时可用

指定权重绘制使用的顶点类型。

骨骼
----------------------------------------------------------------------

设置顶点权重绘制的目标骨骼。

归一化
----------------------------------------------------------------------

.. note::
    仅笔刷类型为基础笔刷时可用

归一化骨骼权重。顶点类型非 BDEF1 时显示。

* BDEF2/SDEF 时，根据第一个权重结合第二个权重调整为 1.0
* BDEF4/QDEF 时，将骨骼设定的权重合计值分别除以各权重进行调整

半径
----------------------------------------------------------------------

设置笔刷的半径。

增量
----------------------------------------------------------------------

.. note::
    仅笔刷类型为喷枪时可用

设置笔刷涂抹位置权重的加算增量。

通常为增加权重的行为，但也可以设为负数来减少权重。

自动归一化
----------------------------------------------------------------------

.. note::
    仅笔刷类型为喷枪时可用

设置是否调整顶点权重使其不超过 1.0。

创建多段骨骼
----------------------------------------------------------------------

创建多段骨骼。有父级和子级两种类型，各有不同，但复制选中的骨骼是共同点。

* 父级

  * 以选中的骨骼为父级，创建的多段骨骼为子级
  * 如果创建前选中骨骼自身也是父级，则会被多段骨骼替换
  * 骨骼名添加 ``+``
  * 「:ref:`CCDE11E1-3416-425D-80DF-A347F79E7BDD`」创建的「组」的创建处理是对「中心」应用此处理，基本原理相同

* 子级

  * 以选中的骨骼为子级，创建的多段骨骼为父级
  * 选中的骨骼的父级被替换为多段骨骼，父级信息被多段骨骼继承
  * 骨骼名添加 ``-``

批量模型变形
==========================================

.. note::
    批量模型变形仅更新模型对象的位置信息。

按「身高基准」或「数值输入」指定的数值对模型进行批量变形。

身高基准
------------------------------------------

执行与「`身高158cm插件 <https://seiga.nicovideo.jp/seiga/im2597790>`_」基本相同的处理。

身高基准的情况与将「数值输入」的 Scale 以「放大率」应用的处理相同。

.. note::
   「A. MMD 中模型的身高」是通过对静止状态下所有顶点位置的 Y 轴最低值与最高值取差值计算得出的。
   因此，除非直接编辑顶点位置，否则即使移动模型该值也不会变化。

.. csv-table::

   A. MMD 中模型的身高,以 MMD 显示单位显示模型身高。只读。
   B. MMD 中的厘米单位,MMD 显示单位转换为厘米单位时的数值。
   C. 校正用厘米,用于校正鞋子或帽子等增加的高度的厘米单位数值。
   厘米单位的模型身高 (A * B + C),显示计算结果。更改此值会改变放大率。
   放大率,显示计算结果与更改结果的放大率差值。

更改「厘米单位的模型身高」的值后点击「应用」即可执行模型变形。点击「重置」可恢复初始值。

数值输入
------------------------------------------

数值输入将输入的 Translation/Rotation/Scale 转换为矩阵并批量应用。

- Translation
- Rotation
- Scale

变形层级
==========================================

.. note::
    骨骼变形按以下顺序排序后执行：

   * 「是否有物理运算后计算」

     * 无物理运算后计算的优先

   * 变形层级顺序

     * 变形层级值越小越优先

   * 骨骼编号顺序

指定变形层级。用于控制变形顺序，从 PMD 转换时若使用了多个 IK，可能会预先指定变形层级。

父骨骼相关文字显示为黄色时，可能涉及以下问题。这是基于上述骨骼变形排序规格的，
可能导致子骨骼在父骨骼之前变形的反转现象，产生未考虑父骨骼变形的变形问题。

* 父骨骼的「物理运算后计算」为「启用」且子骨骼的「物理运算后计算」为「禁用」
* 父骨骼在子骨骼之前，且父骨骼的变形层级值大于子骨骼
* 父骨骼在子骨骼之后，且父骨骼的变形层级值等于或大于子骨骼

指定骨骼是否附带旋转赋予。

旋转赋予是一种当父骨骼旋转时，该骨骼以相同旋转量跟随父骨骼的机制。旋转量可通过赋予率改变。
此外，将父骨骼设为 IK 链接并通过该 IK 链接自动设置旋转量时也适用。

父骨骼
----------------------------------------------------------------------

指定联动的父骨骼（赋予父）。

赋予率
----------------------------------------------------------------------

指定比例。为 1.0 时应用与父骨骼相同的移动量。设为负数可以取消动作。

固定轴
==========================================

指定骨骼是否具有固定轴。

设置固定轴后，无论全局还是局部，都将沿指定的轴变形。此外，相对 IK 的角度限制也优先应用。

骨骼连接显示中显示为紫色。通过视口右下角手柄操作时不显示轴。

固定轴
----------------------------------------------------------------------

.. caution::
    全部设为 0 将导致非法轴，引起骨骼操作时的异常动作，请不要设置。

指定固定轴的向量值。

局部轴
==========================================

指定骨骼是否具有局部轴。

.. note::
    局部轴从 X 轴及 Z 轴的向量计算 Y 轴，并自动计算为正交。因此没有 Y 轴的设置项。

    父骨骼包含「右臂」或「左臂」时，即使不设置局部轴也会自动设置局部轴。如果已设置局部轴则优先使用局部轴。

设置局部轴后，当变形方式为局部时，从视口右下角手柄操作时将沿指定轴变形（全局时不应用）。

X轴
----------------------------------------------------------------------

.. caution::
    全部设为 0 将导致非法轴，引起骨骼操作时的异常动作，请不要设置。

指定 X 轴方向的向量值。

Z轴
----------------------------------------------------------------------

.. caution::
    全部设为 0 将导致非法轴，引起骨骼操作时的异常动作，请不要设置。

指定 Z 轴方向的向量值。

==========================================

指定刚体的动作类型。

.. csv-table::

    类型,说明
    全部反映运算结果,将物理运算结果反映到骨骼上
    仅反映旋转,仅将物理运算结果中的旋转反映到骨骼上（忽略移动）

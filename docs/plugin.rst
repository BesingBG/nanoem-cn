==========================================
插件
==========================================

.. important::
    使用插件需要 29.2.0 及以上版本。此外，插件的提供及安装方式今后可能变更。

安装方法 (macOS)
******************************************

* 在 Finder 中右键点击 nanoem 应用，选择「显示包内容」
* 进入 ``Contents`` > ``Plugins``，将插件复制到 ``Plugins`` 文件夹

  * 例如「半标准骨骼插件」的情况下，将 ``plugin_ssb.dylib`` 复制到 ``Plugins`` 文件夹

* 重新启动 nanoem
* 确认菜单「编辑」>「模型插件」中出现要安装的插件名称

  * 例如「半标准骨骼插件」的情况下，会显示「半标准骨骼插件」

半标准骨骼插件
******************************************

`下载「半标准骨骼插件」(macOS 版) <_static/plugins/plugin_ssb-1.3.0.zip>`_

.. important::
    「半标准骨骼插件」是分发运动中可能强制要求的重要插件，因此作为特例进行移植和分发，
    但原则上不移植 PMDEditor/PMXEditor 系的插件。敬请谅解。

    Windows 版没有分发计划（因为可以使用 PMDEditor/PMXEditor 的环境，没有理由特意使用 nanoem 的插件）。

    支持英文名称 ``Semi-Standard Bone Plugin``（移植源的原始版本不支持英文）。

.. warning::
    使用「半标准骨骼插件」相当于改造模型，请在使用插件前确认模型的使用条款。
    但部分模型在分发阶段已经预先包含了半标准骨骼插件创建的骨骼，此时无需执行。

.. note::
    执行包含「半标准骨骼插件」在内的模型插件时，会覆盖保存原模型。因此，会自动创建执行前的模型数据备份，并以 ``[模型文件名]_backup_at_[年月日]_[时刻].pmx`` 的形式保存到目标模型所在文件夹
    （例如模型文件名为「初音未来」、执行时间为「2020年7月7日12时39分51秒」时，备份文件名为 ``初音未来_backup_at_20200707_123951.pmx``）。

    如果执行源为 PMD，**请务必创建备份**。因为内部实现在加载模型时会转换为 PMX。

    如果要将模型恢复到插件执行前的状态，请将备份文件复制回原模型文件。无法禁用备份创建。

「半标准骨骼插件」是 :ref:`7F24495C-52C6-4659-A309-0E75CAB72D3B`，实现了与 Soboro 开发的 PMDEditor/PMXEditor 插件「半标准骨骼插件」几乎相同的功能。

`Soboro 的半标准骨骼插件解说视频请点击此处 <https://www.nicovideo.jp/watch/sm14956092>`_

该插件自动创建标准模型 ``初音未来.pmd`` 中不存在但被广泛使用的骨骼（如果已存在则跳过处理），原因如下：

- 便于制作运动
- 提高运动的自由度
- 无需直接修改分发运动即可进行修正

  - 旋转附加的骨骼主要用于此用途

根据分发运动的不同，有时必须使用半标准骨骼插件创建的骨骼（虽然没有也能加载，但可能产生运动制作者预期之外的动作）。

* 末尾带 ``*`` 的表示会执行顶点骨骼重新配置及权重绘制（以下简称自动重新配置）
* 开头带 ⚠️ 的表示缺少「必需骨骼」，执行时会产生错误

  * 发生以上错误时，模型不会被修改，保持原样
  * 「必需骨骼」以「中文」的骨骼名称判断
  * 骨骼名称判定中，全角英数字和半角英数字视为不同字符

手腕扭转骨骼 *
==========================================

创建「右腕捩」和「左腕捩」。分别创建在「右腕」与「右肘」、「左腕」与「左肘」之间。

此外，还会创建以扭转骨骼为父级的、旋转附加率为 0.25/0.5/0.75 的三个旋转附加骨骼。

必需骨骼
------------------------------------------

* 右腕
* 右肘
* 左腕
* 左肘

旋转自动修正
==========================================

指定创建「手腕扭转骨骼」时是否根据映射到手腕的顶点进行位置修正。

手部扭转骨骼 *
==========================================

创建「右手捩」和「左手捩」。分别创建在「右肘」与「右手首」、「左肘」与「左手首」之间。

此外，还会创建以扭转骨骼为父级的、旋转附加率为 0.25/0.5/0.75 的三个旋转附加骨骼。

必需骨骼
------------------------------------------

* 右肘
* 右手首
* 左肘
* 左手首

上半身2骨骼 *
==========================================

创建「上半身2骨骼」。创建在「上半身」与「首」之间。

位于上半身和首之间即胸部的位置，是使用频率极高的骨骼，可以更容易地调整身体倾斜。

必需骨骼
------------------------------------------

* 上半身
* 首

腰部骨骼
==========================================

创建「腰部骨骼」。创建在「下半身」与「足」之间。

此外，「右足」与「腰」之间创建「腰キャンセル右」，「左足」与「腰」之间创建「腰キャンセル左」。
顾名思义，这是旋转修正为 -1.0 的旋转附加骨骼，用于控制抖动。

必需骨骼
------------------------------------------

* 下半身
* 右足
* 左足

足部 IK 父级
==========================================

.. note::
    请注意创建的骨骼「足IK親」中的 ``IK`` 是全角而非半角英数字。

创建「右足IK親」和「左足IK親」。创建为「右足ＩＫ」和「左足ＩＫ」的父级。

必需骨骼
------------------------------------------

.. caution::
    是全角英数字的「ＩＫ」，而非半角英数字的「IK」，请注意区分。

* 右足ＩＫ
* 左足ＩＫ

足尖 EX *
==========================================

创建「右足先EX」和「左足先EX」。此外还会创建以下旋转附加骨骼：

* 右足D
* 右ひざD
* 右足首D
* 左足D
* 左ひざD
* 左足首D

这些旋转附加骨骼用于在不直接修改原始运动的情况下添加额外的旋转修正。

必需骨骼
------------------------------------------

.. caution::
    是全角英数字的「ＩＫ」，而非半角英数字的「IK」，请注意区分。

* 右足
* 右ひざ
* 右足首
* 右つま先ＩＫ
* 左足
* 左ひざ
* 左足首
* 左つま先ＩＫ

使足 D 骨骼可操作
==========================================

.. caution::
    需要勾选「自动注册到骨骼显示框」

指定是否将「足先EX」创建的末尾为 D 的骨骼添加到时间轴的显示框中。

手持配件用虚拟骨骼
==========================================

创建「右ダミー」和「左ダミー」。分别创建在「右手首」与「右中指１」、「左手首」与「左中指１」之间。

用于通过外部父级让模型手持配件类附件。

必需骨骼
------------------------------------------

.. caution::
    是全角英数字的「１」，而非半角英数字的「1」，请注意区分。

* 右手首
* 右中指１
* 左手首
* 左中指１

肩部取消骨骼
==========================================

创建以下骨骼。P 作为右肩或左肩的父级，C 创建在右肩或左肩与右腕或左腕之间。

* 右肩P
* 右肩C
* 左肩P
* 左肩C

P 表示父级，C 表示取消，C 作为附加率为 -1.0 的旋转附加骨骼创建。

必需骨骼
------------------------------------------

* 右肩
* 右腕
* 左肩
* 左腕

拇指 0 骨骼 *
==========================================

创建「右親指０」和「左親指０」骨骼。分别创建在「右手首」与「右親指１」、「左手首」与「左親指１」之间。

必需骨骼
------------------------------------------

.. caution::
    是全角英数字的「１」，而非半角英数字的「1」，请注意区分。

* 右手首
* 左手首
* 右親指１
* 左親指１

拇指局部轴设置
==========================================

在创建拇指 0 骨骼时额外设置各拇指骨骼的局部轴。

沟槽骨骼
==========================================

创建「グルーブ」骨骼。放置在「センター」骨骼之后。

这是所谓的骨骼多级化的一种，用于从实质上控制所有动作的センター骨骼中分离上下动作。

必需骨骼
------------------------------------------

* センター

所有父级
==========================================

创建「全ての親」骨骼。设置为最顶级。

顾名思义，作为所有骨骼的父级，用于在不直接编辑各骨骼的情况下修正模型本身的位置。
但是，仅限制作分发用时，由于可能因上述原因产生干扰，应避免使用。

不需要必需骨骼。

操作中心
==========================================

创建「操作中心」骨骼。设置为最顶级（优先级高于「全ての親」）。

这是一种特殊处理的骨骼，用于在 :ref:`6BECA538-F9C4-4628-88EB-7E99C046115F` 中设置为相机视点中心
（选择模型后在「视图」面板的「模型」中勾选复选框即可生效）。
因此，即使移动操作中心骨骼，模型本身也不会移动。

不需要必需骨骼。

自动注册到骨骼显示框
==========================================

设置创建骨骼时是否注册到时间轴的显示框。

以下骨骼在创建时，如果「依赖的骨骼」没有显示框，会自动创建「センター」框并移动到该框：

.. csv-table::

   骨骼名称,依赖的骨骼名称
   腰,下半身
   グルーブ,センター
   全ての親,(第一个骨骼)
   操作中心,(第一个骨骼)

(材质选择)
==========================================

窗口右侧排列材质列表，可以选择自动重新配置的目标材质。
例如，对于与模型一体的配件等不希望自动重新配置的材质，可以取消勾选。

.. note::
    如果顶点关联了多个材质，优先采用排除自动重新配置的设置

如果不设置任何内容，所有材质均为自动重新配置的目标。

新建项目
==========================================

创建新项目。

如果已有任何更改，会显示是否保存的确认对话框。
新项目创建后，无法撤销回原项目。

.. _EEE59B7A-FB14-48E3-B63F-D39AF815CE51:

新建模型
==========================================

.. note::
    此为模型编辑用途的功能，默认不显示。使用时需从「:doc:`preference`」中勾选「:ref:`F517A3B9-3273-4FE3-BD1E-4EDA53843140`」。

    由于处理特性，从「:ref:`1F03E7C8-BB94-44D9-B54E-CF707EB6981F`」创建项目后，需要先保存到文件再执行。

创建一个空模型并保存到文件中后添加。创建的模型数据基于以下规格：

* 仅创建「中心」骨骼
* 显示框中创建「中心」骨骼的特殊框及空元素的「表情」显示框
* 顶点、面、材质、变形、刚体、关节、软体分别为空元素

模型名会自动创建为「新模型」后加随机生成的字符串后缀。

打开项目
==========================================

加载以下格式的项目文件：

- ``.pmm``

  - MikuMikuDance 的项目文件
  - 移动读取源文件后将无法读取

    - 读取源文件包括模型、配件、效果、音源、背景视频

- ``.nmm``

  - 从 1.23.0.0 引入的第三代项目文件
  - 与 nma 格式相比保存较快，但与 pmm 格式一样，移动读取源文件后将无法读取

- ``.nma``

  - nanoem 的第二代项目文件
  - 内容为 ``zip`` 格式，可将扩展名改为 ``zip`` 后使用相应的解压软件解压
  - 保存较慢（取决于项目），但可在其他 PC/Mac 上读取

    - 与 pmm/nmm 不同，内容全部包含在内，即使删除读取源文件也可恢复

- ``.nanoem``

  - nanoem 的第一代项目文件
  - 移动读取源音源或背景视频后，仅该文件无法读取

    - 模型、配件和效果包含在其中，即使删除读取源文件也可读取

  - 仅 macOS 版

如果已有任何更改，会显示是否保存的确认对话框。
打开并加载项目文件后，无法撤销回原项目。

打开
==========================================

模型
------------------------------------------

加载 `.pmd` 或 `.pmx` 格式的模型文件。同一模型文件名带有 `.fx` 扩展名时同时加载效果。

.. image:: images/confirm_loading_model.png

正常加载后会打开确认对话框，点击 `OK` 后才首次显示。
点击 `取消` 会取消后续加载（失败时显示错误对话框）。

如果存在效果文件且效果插件禁用，会显示是否启用的确认画面。
取消则模型加载被取消。

.. tip::
    除了通过菜单加载外，还可以通过以下方式加载（确认对话框显示方式相同）：

   - 选择文件后拖放到 nanoem 窗口
   - 从「模型」面板的「加载」选择文件

    此外，如果效果文件同时被加载，当效果文件被修改时，效果会自动重新加载。

.. _14C11FDE-A0FC-4415-A408-383B0132F735:

配件
------------------------------------------

加载 `.x` 格式的配件文件。同一配件文件名带有 `.fx` 扩展名时同时加载效果。

正常加载后配件会直接显示，加载的配件会被添加到「配件」面板中（失败时显示错误对话框）。

如果存在效果文件且效果插件禁用，会显示是否启用的确认画面。
取消则配件加载被取消。

.. tip::
    除了通过菜单加载外，还可以通过以下方式加载：

   - 选择文件后拖放到 nanoem 窗口
   - 从「配件」面板的「加载」选择文件

    此外，如果效果文件同时被加载，当效果文件被修改时，效果会自动重新加载。

模型姿势
------------------------------------------

.. caution::
  - 即使加载了姿势，关键帧也不会被注册，搜索后会恢复原状，因此务必注册关键帧
  - 未选择模型时无法执行

加载 `.vpd` 格式的姿势文件。

正常加载后，模型会根据姿势文件的内容变形（失败时显示错误对话框）。
也兼容 MikuMikuMoving 采用的包含变形变形的扩展格式。

模型运动

音源
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

将音源加载到项目中。

.. caution::
    项目最多只能加载一个音源。加载其他音源时，会先删除正在使用的音源再进行加载。

.. note::
    5.1ch 或 7.1ch 等多声道音源也可加载，但播放处理取决于使用的操作系统及播放设备。

可加载的音源文件因 nanoem 版本及包含的编解码器而异，请务必确认实际能否加载。

- Windows 版及 macOS 版通用

  - 线性 PCM（即未压缩的音源）
  - MP3

- macOS 版可加载

  - AAC

背景视频
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

将视频加载到项目中。加载的视频将作为视口的背景视频显示。

.. note::
    项目最多只能加载一个视频。加载其他视频时，会先删除之前的视频再进行加载。

.. tip::
    按住 SHIFT 键操作画面右上角的相机缩放及箭头图标可调整视频的位置或缩放比例。

可加载的视频文件因 nanoem 版本及包含的编解码器而异，请务必确认实际能否加载。

- Windows 版及 macOS 版通用

  - RawVideo（即未压缩的视频）
  - `UtVideo Codec <http://umezawa.dyndns.info/wordpress/?cat=28>`_
  - `Grass Valley HQX Codec <https://pro.grassvalley.jp/download/gv_codec_option.htm>`_

    - ``UtVideo`` 及 ``Grass Valley HQX`` 是压缩视频格式，解码负载较大，可能成为降低 FPS 的因素

保存
==========================================

导出项目文件。

从新建项目创建时，首次会打开文件对话框。
第二次以后或从「打开项目」打开时，保存到同一文件。

- Windows 下为 `.nma` 或 `.nmd` 或 `.pmm` 格式
- macOS 下为 `.nma` 或 `.nmd` 或 `.pmm` 或 `.nanoem` 格式

关于 NMA/NMM 格式保存的限制
------------------------------------------

- 不能从 nma/nanoem 格式保存为 nmm/pmm 格式
- 可以从 nmm 格式保存为 nma/nmd/nanoem 格式
- 从 nma 格式保存为 nmm 格式可通过以下步骤实现

  - 将 nma 文件扩展名重命名为 zip 并解压
  - 用新项目重置项目
  - 加载所有解压出来的文件
  - 以 nmm 格式保存

保存源与保存目标的矩阵如下（下方向为保存源，右方向为保存目标）：

.. csv-table::

  ,nanoem,nma,nmm,pmm
  nanoem,⭕,⭕,❌,❌
  nma,⭕,⭕,❌,❌
  nmm,⭕,⭕,⭕,⭕
  pmm,⭕,⭕,⭕,⭕

.. _D90328CC-C39A-4854-BB48-B49039D8E31B:

关于 PMM 格式保存的限制
------------------------------------------

.. important::
   导出为 pmm 格式时，请保留原始项目文件。

   为了在 MMD 中加载而保存时，需要保存到与 MMD 可执行文件同一层级的 ``UserFile`` 文件夹中。
   这是因为 MMD 的规格是以 ``UserFile`` 为基准加载文件。

从 31.0 开始实现了 pmm 格式的保存。但由于规格差异，有以下注意事项：

- 保存为 MMD 9.0 以上可读取的 PMM 2.0 格式

  - 请注意不会保存为 MMD 9.0 以下可读取的 PMM 1.0 格式
  - 暂无计划支持保存为 PMM 1.0 格式

- 模型及配件合计最多 255 个
- 模型或配件的路径名最多 255 字节。超过此长度无法加载

  - 使用日语文件名时会短于 255 字节
  - 以 ShiftJIS 保存，因此路径名中使用 emoji 等将无法加载

- 由于渲染顺序的规格差异，导出时按所有模型、所有配件的顺序保存

  - 例如，如果渲染顺序为「模型、配件、模型」，则会被整理为「模型、模型、配件」

- MMD 的规格对可加载的关键帧数量有上限

  - 相机上限为 1 万个关键帧，模型上限为 5 万个关键帧
  - 执行大量关键帧注册的「:ref:`10C1A1A4-7F7F-479A-A264-2FF9EB4577D4`」时可能触发关键帧数量限制

- 显示框的展开/折叠状态不保存，以全部折叠状态保存
- 重力关键帧在 nanoem 中未实现，因此不保存

  - 仅关键帧的重力设置本身会被保存

- 布局信息不保存
- (仅 33.4 以下时) 关键帧选中状态不保存

另存为
==========================================

与「:ref:`8859DEE8-5813-4ED9-945E-0A01BCCF694A`」相同，但无论项目更改状态如何，始终打开文件对话框并需要指定保存位置。

导出
==========================================

模型姿势
------------------------------------------

.. caution::
  - 模型姿势与运动不同，保存的不是关键帧而是「所有骨骼及变形的状态」

    - 由于上述规格，即使未注册关键帧，变形状态也会被保存

以 `.vpd` 格式将当前帧位置的所有骨骼及变形的状态导出到文件。

模型运动
------------------------------------------

.. caution::
  - 未选择模型时无法执行
  - 运动加载时因骨骼或变形在模型中不存在而被忽略的关键帧不会被注册

将所选模型中的所有关键帧以 `.vmd` 或 `.nmd` 格式导出到文件。

相机运动
------------------------------------------

将相机的所有关键帧以 `.vmd` 或 `.nmd` 格式导出到文件。

光源运动
------------------------------------------

将光源的所有关键帧以 `.vmd` 或 `.nmd` 格式导出到文件。

模型 ※ 1.20 以后
------------------------------------------

将当前选中的模型以 `.pmx` 格式导出到文件。

.. caution::
   * nanoem 启动时设置项中的「启用模型编辑功能」未勾选时不显示。因此需要勾选该项目后重启 nanoem
   * 导出目的地请指定与加载时相同的文件夹。作为模型格式的规格，在不同文件夹导出时纹理将无法正确显示

图像（导出）
------------------------------------------

.. image:: images/export_image.png

.. hint::
   * 如需包含透明，请以 `.png` 格式输出。其他格式因规格无法包含透明，可能无法正确显示。
   * 图像输出采用先重置一次物理运算，再进行帧移动后输出的机制。由于此规格，直接进行图像输出可能无法再现物理运算。

     * 如需保持物理运算导出，请先执行「:ref:`10C1A1A4-7F7F-479A-A264-2FF9EB4577D4`」导出为图像输出用的项目，然后再进行图像输出。

将当前帧位置的视口导出为图像。按以下步骤开始导出：

1. 项目未保存时显示项目保存确认画面
2. 首先显示导出设置（尺寸指定等）对话框
3. 打开指定保存位置的文件对话框
4. 开始将图像导出到保存位置

视频（导出）
------------------------------------------

.. image:: images/export_video_1.png

导出为视频文件。按以下步骤开始导出：

.. note::
   * 输出视频的帧率取决于「播放时帧率」，为 30FPS 或 60FPS。无丢帧。

     * 如需加入丢帧或降低到 24 FPS，请使用「:ref:`28185A65-88E5-4C4C-BF60-41BBB5520B70`」中介绍的视频编辑软件进行更改。

.. hint::
   * 如需包含透明，请参考「:ref:`8DE98D42-1894-4002-B629-4D64580EF404`」。
   * 视频输出与图像输出一样，采用先重置一次物理运算，再进行帧移动后输出的机制。在指定帧范围时可能无法再现物理运算。

     * 因此，如需保持物理运算导出，请先执行「:ref:`10C1A1A4-7F7F-479A-A264-2FF9EB4577D4`」导出为视频输出用的项目，然后再进行视频输出。

1. 项目未保存时显示项目保存确认画面
2. 打开视频设置对话框
3. （取决于「启用 OS 自带编码器」的设置）

  - 勾选「启用 OS 自带编码器」时，进入第 4 步
  - 取消勾选「启用 OS 自带编码器」时，从 Plugins 指定插件

    - 不确定使用哪个时推荐 ``plugin_lsmash``

4. 打开指定保存位置的文件对话框
5. 开始将视频导出到保存位置

.. note::
    与图像输出不同，视频导出是耗时且高负载的操作，导出前请先关闭所有 nanoem 以外的应用程序，导出期间不要启动其他应用程序，耐心等待。

输出分辨率
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

选择视频输出时的分辨率：

- 与视口相同
- Application Default (960x640)
- XGA (1024x768)
- 720p (1280x720)
- WXGA (1600x900)
- UXGA (1600x1200)
- 1080p (1920x1080)
- WUXGA (1920x1200)
- WQHD (2560x1440)
- WQXGA (2560x1600)
- 4K (3840x2160)
- 8K (7680x4320)

「与视口相同」使用「:ref:`305111E6-1E3B-425E-84E2-8227A6FA94C9`」中的「输出尺寸」设置。分辨率越高输出越耗时。

保持视口的宽高比
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

启用时使用视口的宽高比进行输出。

这样可以防止因禁用时由输出分辨率决定宽高比而导致的变形。
同时可以正确输出纵向分辨率（由于输出分辨率中没有此选项，需要设置视口）。

禁用时与 26.0 之前的行为相同，宽高比由输出分辨率决定。

启用帧偏移抑制
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

当帧率超过垂直同步时，帧移动时可能产生偏移，此功能可抑制此现象。

禁用时将禁用垂直同步，导出速度会变快，但会出现上述帧偏移问题，因此仅用于制作过程中的确认。
启用「启用 OS 自带编码器」时不受影响。

Plugins
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. caution::
    使用 34.1 以下的 ``plugin_ffmpeg`` 输出时，请使用立体声且频率为 44100Hz 的音源。
    这是由于缺陷导致的，已在 34.1 中修复。

指定用于视频导出的插件。

- ``plugin_avfoundation`` (仅 macOS 版)

  - 使用 AVFoundation 进行视频导出的插件
  - 可保存格式为 mp4/mov
  - 无可设置项目

- ``plugin_ffmpeg``

  - 使用 ffmpeg 内部库进行视频导出的插件
  - 仅可保存为 avi 格式
  - Video Codec

    - 从以下中选择保存的视频格式：

      - Raw Video

        - 未压缩视频，实质上与 plugin_lsmash 相同

      - UT Codec Video

        - 无损压缩视频，因压缩处理保存耗时较长，但文件大小可缩减约一半

  - Video Pixel Format

    - 影像在视频导出中的保存格式，从以下选择：

      - RGB
      - RGBA
      - YUV420P
      - YUV422P
      - YUV444P

    - 基本使用 RGB，使用透明时使用 RGBA，允许色彩劣化但希望缩小文件大小时使用 YUV

  - Audio Codec

    - 目前仅 PCM
    - 音源为单声道时转换为立体声
    - 音源频率低于 44100Hz 时提升至 44100Hz
    - 使用非 16bit 的音源时统一归一化为 16bit

- ``plugin_lsmash``

  - 输出未压缩视频的插件

    - 请注意与 AviUtl 插件之一的 `lsmash-works <https://pop.4-bit.jp/?page_id=7929>`_ 不同

  - 仅可保存为 mov 格式
  - Estimated export video size 是视频导出后的估算大小

    - 例如导出 3 分钟 1280x720 的 60FPS 视频时约为 30GB

- ``plugin_gif``

  - 输出 gif 的插件
  - 仅可保存为 gif 格式，无可设置项目
  - 由于编码处理，视频导出完成后画面不会立即恢复，但会随时间恢复
  - 计划将来废弃，不推荐使用

    - 推荐替代方案：以 mp4 格式导出视频，然后使用 `gifski <https://apps.apple.com/jp/app/gifski/id1351639930?mt=12>`_ 编码

音频编解码器
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

视频导出时加载了音源的情况下可选择

默认为 `AAC`，但将视频导出时的文件扩展名设为 `mov` 时，可选择 `Apple Lossless` 和 `Linear PCM`

视频编解码器
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

默认仅为 `H.264/AVC`，但将视频导出时的文件扩展名设为 `mov` 时，可选择 `Apple ProRes 422` 和 `Apple ProRes 4444`

视频像素格式
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

目前仅可选择 `RGBA 8bits`。

未来支持 HDR 后将增加 `RGB 10bits A 2bits` 和 `RGBA 16bits float`。

视频配置文件
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

视频配置文件设置在视频编解码器选择 `H.264/AVC` 时的配置文件。其他编解码器忽略。

撤销
==========================================

.. important::
    从 27.0.0 开始，从仅项目单位分离为项目单位（相机模式时）和模型单位（选择模型时）。
    由此有以下变更：

   * 模型操作可分别按模型单位独立「撤销」
   * 非单一模型可完成的操作（例如插入或删除帧）以项目单位记录，因此需要先切换到相机模式
   * 配件操作通过在相机模式下操作，以项目单位记录

撤销上一次操作。

  - 骨骼操作等操作中发生帧移动时，移动前执行的处理为「撤销」的起点
  - 「撤销」及「重做」的操作最多保存 **64** 次。更早之前的操作将被清除
  - 如果鼠标上有「撤销」按钮并且按下，将执行「撤销」处理

.. _E3DC7DFA-5EAB-4F58-88F0-151FBDC1008D:

重做
==========================================

.. caution::

    - 如果在一次「撤销」后执行了其他操作，则无法重做

      - 例如 `A -> B -> [撤销] -> A -> C` 时，`B` 的操作将丢失

取消「撤销」恢复的操作。

  - 「撤销」及「重做」的操作最多保存 **64** 次。更早之前的操作将被清除。
  - 如果鼠标上有「重做」按钮并且按下，将执行「重做」处理

播放
==========================================

.. important::
    如果包含音源，播放设备构成更改时播放中的行为会发生变化。构成更改的检测利用操作系统机制，因此可能无法检测到。此外，此行为无法从设置更改。

   * 检测到添加新播放设备时，暂停播放，更改播放设备后继续播放

     * 例如将耳机插入耳机插孔时

   * 检测到播放设备脱离时，暂停播放，但更改播放设备后不恢复

     * 例如耳机从耳机插孔拔出，切换到其他播放设备时
     * 这是为了防止在其他播放设备播放时意外的漏音

抗锯齿设置
==========================================

.. caution::
    启用后，根据硬件可能会明显变慢或出现「:ref:`596AB6F3-51F6-4C4C-8A0A-5428B6381499`」中提到的意外问题。此时请禁用。

    此外，某些效果可能与抗锯齿功能发生干扰。通常效果的使用说明书中会说明是否需要禁用抗锯齿。
    当使用说明明确指出需要禁用时，请禁用。

设置抗锯齿。初始值为禁用。

启用且数值越大，锯齿越少越清晰，但处理负载相应增加。
此外，即使设为最高设置，如果不可用，系统会自动选择可用的最接近设置（例如 Apple M1 时即使设为「最高设置」也会选择「偏高」）。

- 最高 (MSAAx16)
- 高 (MSAAx8)
- 偏高 (MSAAx4)
- 普通 (MSAAx2)
- 禁用

33.0 之后，设为禁用以外的设置时，视口中显示的骨骼显示等的抗锯齿将启用。
即使处于禁用状态，只要不禁用「:ref:`88592664-60C0-40B8-B14A-06983999A95D`」，设置将被保留。

物理运算
==========================================

切换物理运算的启用设置。启用设置有以下四种：

- 始终启用

  - 编辑及播放时启用物理运算

    - 向前移动帧位置时重置运算
    - 骨骼移动时也进行物理运算

- 仅播放时

  - 仅在播放时启用物理运算
  - 编辑时物理运算禁用

- 跟踪模式

  - 编辑时每移动一帧执行一帧的物理运算

    - 向前移动帧位置时重置运算
    - 与「始终启用」不同，骨骼移动时不进行物理运算

  - 播放时，在播放前重置一次物理运算后启用

- 禁用

  - 编辑及播放时禁用物理运算

.. _F3B3AAC8-0D8C-4409-8439-8764F37F2962:

运算设置
------------------------------------------

设置物理运算的运算参数：

- 加速度

  - 设置重力加速度
  - 加速度乘以方向的结果作为重力设置

- 方向

  - 设置重力方向
  - 要表现浮游的世界时，将 Y 轴设为正而非负，重力将向上

- 时间步长系数

  - 设置每帧物理运算的时间步长系数
  - 通常无需设置，但 :ref:`07C43859-06E8-4AAD-AA73-04414EC6A3FA` 与视频导出的 FPS 不同时，需要调整此值
  - 例如 :ref:`07C43859-06E8-4AAD-AA73-04414EC6A3FA` 为 60FPS，视频导出预期为 120FPS 时，所需的拉伸时间为 2 倍，因此设为 0.5

    - 此时需要使用 :ref:`721C4B9C-55DD-46BD-A506-DA412489831E` 中的「:ref:`0501EDF6-963F-43D4-A17A-40471A0F6D19`」将运动长度拉伸为 2 倍
    - 视频导出本身为 60FPS，但通过拉伸可虚拟实现 120FPS。再将其缩放到 1/5 即可得到 24FPS

.. _10C1A1A4-7F7F-479A-A264-2FF9EB4577D4:

烘培所有模型的运动 ⏪
------------------------------------------

.. important::
    为防止执行运动烘培后无法返回烘培前状态的意外，即使覆盖保存也会显示保存对话框（从 27.2.0 开始应用）

对项目中的所有模型的运动进行物理运算结果的烘培。

* 处理结果与启用「跟踪模式」时相同
* 所有刚体关联的骨骼的关键帧逐帧注册，因此导出的运动会变得庞大
* 烘培后的运动可以导出为 vmd/nmd 格式

    * 但由于 vmd 的规格无法关闭物理运算，需要在加载侧禁用物理运算
    * 此外由于关键帧的注册规格，可能触发关键帧数量上限，导致在 MMD 中无法加载

      * nanoem 中不设关键帧数量限制，只要内存允许即可加载

* 撤销时需要先切换回相机模式再执行

.. _EFE0C3B6-39AF-4210-846A-B329D49B2611:

烘培所有模型的运动（含 IK） ⏪
------------------------------------------------

.. important::
    为防止执行运动烘培后无法返回烘培前状态的意外，即使覆盖保存也会显示保存对话框（从 27.2.0 开始应用）

与 :ref:`10C1A1A4-7F7F-479A-A264-2FF9EB4577D4` 相同，但此功能包含 IK 进行烘培。

* 所有 IK 骨骼将被禁用
* IK 影响下的骨骼的关键帧逐帧注册

  * 结果比普通运动烘培文件更大

* 如果 IK 影响下的骨骼由赋予父级骨骼驱动，则对赋予父级骨骼而非 IK 影响下的骨骼进行烘培处理

启用高分辨率视口
==========================================

.. note::
   macOS 下仅在高分辨率设置时有效

高分辨率液晶对视口的显示负载较大，用于降低显示负载时使用（即禁用）。

性能显示的内容如下：

  * 当前 nanoem 的 CPU 使用率

    * Windows 下为机器本身而非 nanoem 的 CPU 使用率

  * 当前 nanoem 的内存消耗量

将当前选中的配件转换为模型
==========================================

.. note::
   此为模型编辑用途功能，默认不显示。如需使用，需从「:doc:`preference`」中勾选「:ref:`F517A3B9-3273-4FE3-BD1E-4EDA53843140`」。

   转换后的模型按以下规格创建。外观不一定一致，可能需要调整材质。

  * 所有面转换为三角形
  * 材质数与原始配件一致
  * 仅存在「所有父级」骨骼，显示框同样
  * 所有顶点以 BDEF1 映射到「所有父级」
  * 球面纹理扩展名 (sph/spa) 指定时设置为球面纹理
  * 变形、刚体、关节、软体分别为空元素

.. caution::
   此操作无法撤销

将当前选中的配件转换为模型。此操作按以下流程进行：

* 从读取源配件文件转换为模型
* 将转换后的模型以配件文件名的扩展名为 ``pmx`` 的形式保存
* 加载上述文件并作为新模型添加
* 将原始配件运动中的「位置」和「旋转」以注册到「所有父级」骨骼关键帧的形式复制
* 从项目中删除转换后的配件

原始配件会从项目中删除，但读取源配件文件被保留。

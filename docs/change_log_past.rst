=======================================================
变更履历 (31.5.0 以前)
=======================================================

31.5.0 (2021/2/22)
******************************************

功能添加
==========================================

* 加载 nmm 格式项目文件时，配件或模型加载失败时显示无法读取的原因
* 在 :ref:`A83521E4-540E-4C96-8093-07684B994454` 中添加「启用帧偏移抑制」

  * 修复 31.2.0 引入的导出加速超过垂直同步速度时视频导出结果不准确的问题

缺陷修复
==========================================

* 语言设置为英语时翻转粘贴不工作
* :ref:`F3B3AAC8-0D8C-4409-8439-8764F37F2962` 实际上不工作
* ``plugin_avfoundation`` 中音源解码有时失败

  * 可能是 macOS 上 WAV 以外音源加载失败的原因

* 加载包含无连接刚体关节的模型时崩溃

  * 该模型在 MMD 中加载也一定会崩溃，请注意

31.4.0 (2021/1/21)
******************************************

缺陷修复
==========================================

* 执行物理运算烘培时崩溃

  * 内部原因是模型关键帧中物理运算启用/禁用切换时崩溃

* 在关键帧选中状态且插值曲线显示状态下执行撤销时崩溃
* 语言更改时抗锯齿菜单消失且菜单的勾选状态未正确恢复
* 菜单中的地面阴影本应启用却未勾选
* macOS 使用 OS 自带编码器导出结果异常

  * 一定程度上修复了视频导出时容易崩溃的问题，提高了稳定性

31.3.0 (2021/1/15)
******************************************

规格变更
==========================================

* 变形变形时，保存未注册到关键帧的骨骼变形状态

  * 之前变形变形时会重置骨骼的变形状态

* 临时实现 PMX 2.1 中定义的翻转变形和脉冲变形
* 为下个版本的软体支持切换为支持软体的物理运算实现

  * 由于以上变更，物理运算的行为可能发生变化
  * 31.3.0 开始支持加载包含软体的模型，但不会运行

缺陷修复
==========================================

* 不存在顶点的模型中变形处理不执行
* nmm 格式项目保存时，选择了物理运算禁用及跟踪模式以外的处理模式时未保存
* macOS 版项目保存时文件路径包含浊点半浊音时，在 macOS 以外打开项目时配件或模型无法加载

  * 仅在 macOS 上使用时无需处理
  * 如果在 macOS 以外使用，请使用不受影响的 macOS 版执行以下操作：

    * 将相应的配件或模型的运动导出一份，在 31.3 以上重新加载后保存
    * 不仅适用于配件或模型的文件名，也适用于文件夹名

* macOS 版使用 OS 自带编码器导出时可能崩溃
* 特定纹理的解码异常导致使用该纹理的配件或模型出现意外绘制
* 项目播放结束时的处理遗漏导致配件、相机、光源、自身阴影未正确重置
* Windows 版首次启动时崩溃的问题因其他原因仍然存在
* Windows 版播放卡顿

  * 重复播放和暂停时，因音源同步校正处理导致卡顿的问题
  * 上述问题在按下停止而非暂停时，同步校正处理会被重置，卡顿消失

* 内部稳定性改进（针对已确定崩溃位置的问题进行修复）

31.2.0 (2021/1/3)
******************************************

规格变更
==========================================

* 重新设计视频导出处理，提高处理速度

缺陷修复
==========================================

* macOS 版在 Metal 下运行时调整窗口大小时布局崩溃
* macOS 版在 Metal 下运行时有时会挂起且 CPU 高负载无响应

  * 新建项目、重新打开项目、播放或编辑时 FPS 变化时高概率发生

31.1.0 (2020/12/31)
******************************************

规格变更
==========================================

* macOS 版扩展了可用 nanoem 直接打开的文件扩展名

  * nma
  * nmd
  * nmm
  * pmd
  * pmm
  * pmx
  * vmd

缺陷修复
==========================================

* 现有运动导入后保存项目时可能以不完整状态保存

  * 可能与保存项目时「由于尝试保存不完整的数据，保存已中断」错误原因相同

* 背景视频未正确渲染

  * 原因在于 31.0.0 的渲染处理变更

* 内部变更改善了使用 ``TEXTUREVALUE`` 的效果的处理速度
* 每个模型需要渲染目标的效果中内存使用量激增
* Metal 上使用点绘制的效果出现异常渲染

31.0.0 (2020/12/25)
******************************************

功能添加
==========================================

* 临时支持 Apple Silicon Mac

  * 由于渲染处理的全面重审，Apple Silicon 以外的平台也可能改善性能
  * nanoem > Preferences... > 「系统信息」的 CPU 显示为 ``ARM (64-bit)`` 则表示以 Apple Silicon 原生运行

* 实现 PMM 文件导出

  * 注意事项请参考 :ref:`D90328CC-C39A-4854-BB48-B49039D8E31B`

* 支持 PerMonitor v2

  * 切换到 DPI 不同的显示器时，菜单字体尺寸能正确跟随
  * 仅 Windows 版

规格变更
==========================================

* 提高内部使用的图形库限制值

  * 使用 31.0 以下版本时不会自动提高，请从 nanoem > Preferences... > Special 点击 Initialize 按钮
  * 正常使用基本不会触发，但大量使用效果时可能会因此崩溃，建议按上述方法提高

* 从 Visual Studio 2015 运行时切换到 Visual Studio 2017 运行时

  * 仅 Windows 版

* 默认禁用 mipmap 生成

  * 因为当前处理潜在的崩溃原因

缺陷修复
==========================================

* 离屏 Main 中各个模型或配件的显示切换及清除未正确工作
* 移动到分辨率缩放比例不同的显示器时比例跟踪不正确

  * Windows 版在支持 PerMonitor v2 的同时进行了修正，macOS 版也进行了同样的修正

* 删除配件时顶点及索引缓冲区未被删除，继续保留在内存中
* 效果的参数画面在特定条件下崩溃
* 渲染队列的一处内存泄漏

30.1.0 (2020/8/31)
******************************************

功能添加
==========================================

* 支持通过拖放加载 WAV (PCM) 音源

30.0.0 (2020/8/12)
******************************************

功能添加
==========================================

* 添加按住鼠标中键移动相机

  * 原本 MMD 有此功能但 nanoem 未实现，现已实现
  * 与右上角的相机移动图标行为相同但移动幅度有所调整

规格变更
==========================================

* 将保存到项目 (nmm 格式) 的路径从绝对路径改为相对路径

  * 通过此次变更，例如在使用 DropBox 等在线存储进行文件同步时，可以在其他机器上加载
  * 29.2.0 之前保存的项目文件可以按传统方式加载，但新项目将以相对路径保存

    * 可通过「:ref:`2F442197-62C2-468A-889A-E4FDF5D6E3F2`」切换设置

* 项目加载时，如果配件、模型、模型材质分配的效果内容与项目保存时不同，则显示错误

  * 以前会跳过加载，但存在用户无法察觉可能误以为文件丢失的问题，因此改为明确显示错误

* 将相机变形方式的初始值从 ``Global`` 改为 ``Local``

  * 因为 MMD 中 ``Local`` 是初始值，故跟随
  * 模型仍保持 ``Local`` 为初始值

* 图像或视频导出前添加确认是否保存项目的对话框

  * 为防止视频导出中崩溃导致回退的问题而添加

* 图像导出时如果存在未注册的骨骼或变形，则显示错误

  * 图像导出在规格上会发生帧移动，因此作为未注册骨骼或变形会丢失问题的对策

缺陷修复
==========================================

* 项目初始化有时崩溃
* 编辑及播放中的帧率「无限制」不工作
* IK 禁用后 IK 链接的旋转未归零，持续保留

  * 相关功能：IK 启用/禁用切换已改为立即反映

* IK 链接的骨骼位于 IK 骨骼后方时无法正常变形
* 通过右下手柄移动相机时， ``Local`` 被当作 ``Global`` 处理
* 右上图标相机移动与 MMD 的行为不同
* 按住 Shift 键时无法移动或缩放相机

  * 原因在于与背景视频操作冲突，未加载背景视频时修正为可快速移动或缩放相机
  * 加载背景视频后行为会被覆盖，请注意

* 模型插件执行后保存的模型在 MMD 中无法加载
* 使用 Shift 或 Command（Ctrl）键操作手柄移动或旋转时位置跳跃
* Windows 版不显式添加扩展名时文件保存失败

  * 已修正为即使没有扩展名也仅凭文件名即可保存

28.2.0 (2020/4/22)
******************************************

规格变更
==========================================

* 将 :ref:`D1BF8CFD-152D-4D1C-8B23-1FC6A4EBF391` 默认改为禁用

  * 因为启用时可能发生模型显示崩溃，加之模型显示负载分散的设置缺陷修复的影响
  * macOS 版使用 28.1.0 以下时，通过重新设置也会以默认禁用状态启动

缺陷修复
==========================================

* 使用 ScriptExternal 的后期效果分配效果到材质时无法正确渲染
* 帧移动时撤销位置重设时多撤销了一次

  * 例如执行以下操作时，本应回到关键帧操作，但却回到了骨骼移动1

    * 骨骼移动1
    * 关键帧操作
    * 骨骼移动2
    * 帧操作

* 模型模式下操作相机时，相机操作成为撤销操作对象，导致过度撤销

  * 本应为相机模式的撤销操作，因此将模型模式下的相机操作从撤销操作对象中移除

* LoopByCount + LoopByCount + LoopGetIndex 中取第一个 LoopByCount 的值

  * 具体表现为 ``Numbers_Float4x4.fx`` 中出现显示异常

* 离屏分配效果的顶点纹理以项目为单位被引用导致重用的问题修复

  * 具体表现为存在两个以上模型时使用 MotionBlur 会出现显示异常

* ray-mmd 在 macOS 上使用时，特定通道的着色器编译失败导致无法正确显示
* macOS 上「:ref:`D1BF8CFD-152D-4D1C-8B23-1FC6A4EBF391`」仅对一个模型生效

  * 已修正为对所有模型处理

28.0.0 (2020/3/25)
******************************************

.. important::
    由于效果插件及其关联的本体进行了大规模修改，尤其在效果使用方面可能与 27.x 之前的行为差异很大。

    此外，所有版本的 macOS 在 OpenGL 下的效果使用已停止支持。虽然可以运行，但已不在缺陷修复范围内，请注意。

功能添加
==========================================

* 跟踪效果文件修改的自动更新
* 在视口设置画面中添加「启用透视背景」

  * 启用后透视背景生效，图像及视频导出时透视值也会反映
  * 以前使用效果时透视度被忽略，此次变更后启用时会反映

    * 但需要效果侧支持，且需要修改相应效果文件
    * 对应方法因效果而异，请参考效果附带的 README 或源代码

规格变更
==========================================

* 阴影处理变更

  * 阴影贴图仅用于模型渲染
  * 改善地面阴影渲染中的模糊显示

* 修正效果中逆矩阵的处理为正确方式

  * 可能导致使用逆矩阵的效果出现不兼容的变更

* 修正相机位置的计算处理为正确方式

  * 与上相同影响效果，也影响边缘宽度的显示

* 默认启用 mipmap 生成及各向异性过滤

  * 但在 OpenGL 中 mipmap 处理有问题，因此已禁用

* 加载 16bit RGBA 纹理时不再减色处理

缺陷修复
==========================================

* 效果更新时之前效果使用的内存未被释放，持续保留
* Windows 中抗锯齿设置无效
* 「模型负载分散」禁用时附加 UV 不工作
* Windows 版「模型负载分散」启用时顶点数超过 65536 的模型无法正确显示
* 配件的运动中显示状态和加法有时不反映
* 效果相关修复（含可能成为规格变更的内容）

  * 修正 ``CULLMODE`` 的行为
  * 实现 ``ZENABLE``
  * 模板缓冲区未工作的缺陷
  * 配件的 ``use_texture`` 与 ``use_spheremap`` 设置颠倒的缺陷
  * 支持渲染目标及离屏的 mipmap 生成
  * 支持判断模型或配件是否为加法状态的 ``opadd``
  * 依赖视口大小的渲染目标在非 1.0 缩放后未正确计算的缺陷
  * 子集指定中未能识别仅特定材质编号如 "0" 的缺陷
  * 配件的 toon 判定处理被跳过的缺陷
  * ``normalize`` 计算后仍为 NaN 的部分改为归一化为 0
  * 配件使用 ``CONTROLOBJECT`` 时骨骼绑定后的计算未反映的缺陷
  * ``CONTROLOBJECT`` 中配件或模型未找到时的初始值设置未正确执行的缺陷
  * ``matrix._11_12_13_14`` 等获取指定未正确转换的缺陷
  * 「启用透视背景」功能添加导致 Clear 的 alpha 值强制设为 1 的处理已删除
  * 修正 ``ELAPSEDTIME`` 语义的行为
  * 使用离屏时始终写入 alpha 值
  * 离屏渲染中尝试使用 MRT 时崩溃
  * 实现离屏渲染目标指定的 ``none``
  * mipmap 生成的图像异常的缺陷
  * 配件中渲染地面阴影的通道使用 ``object_ss``
  * 支持 ``MME_MIPMAP``

  * 以前的方式因音源播放延迟导致高 FPS 下卡顿，因此引入高精度定时器同步

    * 基本以高精度定时器为基础，与音源播放位置的偏差较大时使用音源播放位置

23.0.0 (2019/3/6)
******************************************

.. important::
     * 从此版本开始采用语义化版本控制，因此版本号为 23.0.0
     * 由于更改了物理运算的计算方法，与前一版本不兼容

功能添加
==========================================

* 引入 `nmm` 文件格式

  * 与 `nma` 格式相比，仅保存元数据和运动数据的 `pmm` 格式同类文件格式
  * 与 `nma` 格式相比可快速保存，但移动模型文件或音源或背景视频文件后无法正确加载

    * 需要管理好模型、音源或背景视频文件，不要移动 `nmm` 中记录的文件

  * 由于上述规格原因，无法从 `nma` 格式或 `nanoem` 格式保存为 `nmm` 格式

    * 但可以从 `nmm` 格式保存为 `nma` 格式或 `nanoem` 格式

* 支持 HDR 输出

  * 启用需在设置中从 `Color Format` 更改
  * 需要使用支持 HDR 输出的外接显示器及支持 HDR 输出的 Mac

    * 截至 2019 年 3 月，MacBook 系列内置显示器不支持 HDR 输出

* 添加 L-Smash 插件

  * 可以 MOV 格式以原始状态导出

    * 可在 QuickTime Player 中播放
    * 也可导入 iMovie，但会显示警告对话框，未来兼容性不保证

  * 由于未压缩的性质，导出的视频文件非常大

规格变更
==========================================

* 支持 SDEF 蒙皮
* 更改物理运算处理

  * 重新实现了骨骼对齐刚体，该部分有重大变化
  * 同时更改为更严格的判定

* 渲染器为 Metal 时改为在 GPU 上执行蒙皮
* 分离视口与窗口计算，窗口大小更改后保持视口固定
* 视频导出时物理运算启用时强制以跟踪模式计算物理运算
* 从 HockeyApp 迁移到 AppCenter
* 将传统的「光源」按照 MMD 改为「照明」

缺陷修复
==========================================

* 视口下的数值输入完全未反映
* 骨骼手柄拖动导致过度移动及旋转的问题

  * 本应为 MMD 相同的 0.1 单位，却按 1.0 单位移动

* 尝试切换到 OpenGL 渲染器时退出崩溃导致设置未反映
* 60FPS 播放设置中使用切换的场景时视点跳跃
* 视频导出时开头和结尾多输出 1 帧
* 视频导出时相机切换瞬间边缘显示异常粗
* 效果的 TIME 语义中 SyncInEditMode 启用时的值错误以帧数显示

  * MMD/MME 中以秒数计算，因此改为以秒数显示

* 项目文件中背景视频未记录

  * nma 格式情况下，由于保存背景视频本身，根据原始背景视频文件大小可能极度膨胀

34.9.0 (2023/4/2)
******************************************

.. important::
   macOS 版需要 macOS 10.13 及以上版本

缺陷修复
==========================================

* 读取以下条件的模型时，部分纹理无法加载

34.8.0 (2023/1/29)
******************************************

规格变更
==========================================

* 增加支持 BugSur 及以上版本的大图标

缺陷修复
==========================================

* 效果设置画面中，渲染目标的模型绘制开关有时不显示
* 切换渲染目标的模型绘制开关时，渲染目标不重置
* 模型编辑功能启用时，删除变形或 IK 链接会崩溃
* 模型编辑功能启用时，增加 IK 目标骨骼的尝试次数后返回会崩溃

* 修正 Windows 上 CPU 使用率按进程计算

34.2.0 (2021/11/3)
******************************************

缺陷修复
==========================================

* Windows 版启用「:ref:`D1BF8CFD-152D-4D1C-8B23-1FC6A4EBF391`」并加载模型时发生内存泄漏
* Windows 版在渲染器为 OpenGL 时布局略微向上拉伸
* 离屏渲染中绘制了不需要绘制的对象
* 渲染器为 OpenGL 且使用效果时，渲染目标虽未使用 mipmap 却设置了 mipmap 过滤器导致绘制错误
* 效果设置画面图像显示在渲染器为 OpenGL 时垂直翻转

  * 同时调整了纵向拉伸

* 抑制音源加载时出现 ``Cannot find PCM audio buffer`` 无法读取的错误
* 使用 32bit PCM 音源时不显示波形
* 使用 ``plugin_avfoundation`` 导出视频时，若有不适配频率的音源会崩溃

34.1.0 (2021/10/1)
******************************************

缺陷修复
==========================================

* 34.0 修复的模型加载确认对话框显示时的操作中，加载未被阻止，因此追加防止措施
* 模型编辑启用状态下创建新模型后，尝试进入模型编辑画面会崩溃

  * 同时修复了「新建模型」生成的模型未保存到项目的问题

* Windows 版使用 DirectX11 且抗锯齿启用后调整窗口大小时显示蓝色画面
* 满足以下任一条件且使用 mipmap 的后期效果时崩溃

  * 视频导出时以比视口尺寸小的尺寸导出
  * 切换为禁用「:ref:`88592664-60C0-40B8-B14A-06983999A95D`」

* 模型编辑中无法设置反射强度和边缘宽度
* 使用 ``plugin_ffmpeg`` 编码不满足立体声且 44100Hz 条件的音源时，输出的音源产生噪声
* Windows 版进行语言设置时菜单项状态不正常
* 减少视口的锯齿
* 「:ref:`A843137E-D975-47B7-86F1-E018BF189873`」面板中的「补间」误写为「补完」
* 视频导出中，有音源且开始位置设为大于 0 时，音画不同步

  * 无论导出开始位置如何，音源始终从开头开始的缺陷

* 视频导出中，导出的终点可设置大于项目结束帧的问题
* 根据项目的播放 FPS 设置， ``plugin_lsmash`` 的输出估算有时会显示比实际少

34.0.0 (2021/9/17)
******************************************

功能添加
==========================================

* 添加「:ref:`1CE450D5-1101-44CC-AA24-8DD1CAE204E1`」

规格变更
==========================================

* 模型运动加载后，全选模型包含的骨骼或变形对应的关键帧

  * 为与 MMD 行为保持一致

* 关键帧注册时，注册的关键帧也会同时被选中

  * 同上原因
  * 由于处理原因，崩溃恢复不会保存关键帧注册时的选中状态

* nmm 及 pmm 格式在加载及保存时考虑关键帧选中状态

  * nmm 从 33.4.0 以下版本加载的首次仍保持之前的未选中状态
  * 33.4.0 以上保存并加载 nmm 时，关键帧的选中状态将被恢复

缺陷修复
==========================================

* 33.0 以上背景视频已加载但不在视口中显示
* 以 pmm 格式保存时保存处理冻结，除强制结束外无法结束程序
* 模型加载确认等对话框中，可执行各种操作，根据条件可能导致崩溃

  * 对话框显示中执行保存处理时，会显示进度画面但不执行任何操作（原本不应执行）

* 效果使用的图像 mipmap 生成数错误导致可能崩溃
* 使用 ``plugin_lsmash`` 导出视频时取消，除强制结束外无法结束程序

33.0.0 (2021/6/10)
******************************************

功能添加
==========================================

* 大幅强化模型编辑功能

  * 可用功能请参考 :doc:`model`

* 在模型上显示手柄操作时，显示选中骨骼的连接信息
* 在视口右下显示手柄操作时，显示选中骨骼的操作轴
* 添加以下菜单项（下两项为模型编辑用途，默认不显示）

  * :ref:`D102480C-FFFB-43BA-9561-291E1AF4255B`
  * :ref:`5BB93875-36E2-42A2-B232-BD61D8FD131D`
  * :ref:`EEE59B7A-FB14-48E3-B63F-D39AF815CE51`
  * :ref:`07D2C58A-8399-48F6-A21E-C0D49D9C59FF`

* 可将 Grass Valley HQX Codec 编码的视频作为 :ref:`4BF77CBD-F154-479A-8CC6-83F19677CB04` 使用

  * 仅可作为背景视频使用，不能以 Grass Valley HQX Codec 导出视频。也无计划支持导出
  * 由于是基于 ffmpeg 的兼容解码器实现，部分视频可能无法正确加载

* 在「选择」中添加按住 ``Alt + Shift`` 拖动时旋转的功能

  * 实验性功能，可能在无预告情况下变更规格或删除

规格变更
==========================================

* 在模型上显示移动或旋转手柄操作中，未选中的轴显示为半透明
* 对以「右臂」或「左臂」为父级的骨骼自动设置局部轴
* 选中骨骼不可移动或旋转时，视口下方的参数输入的相应项目设为禁用
* 高分辨率视口或抗锯齿启用时，视口中显示的骨骼连接和手柄等的抗锯齿设为启用

  * 变更前为减轻显示负载一律禁用

* 设置画面等子窗口的移动限制为仅拖动标题部分

  * 变更前可拖动子窗口内任意位置移动

* 对隐藏的模型不触发物理运算

  * MMD 中即使模型隐藏也会发生物理运算的碰撞判定，请注意

* 加载运动文件时，检查是相机及照明运动还是模型运动

  * 以前只是忽略，导致误加载时无法识别的问题，改为显示错误
  * 旧版 nanoem 导出的相机及照明运动文件中未设置对象名称，可能会出错

* 加载模型运动时若未选择模型则显示错误
* 加载模型运动时若未找到对应的骨骼或变形则显示警告

缺陷修复
==========================================

* 操作模型上显示的移动或旋转手柄时，位置可能会跳跃
* 更改视口设置时可能导致鼠标光标位置偏移
* Windows 版使用 DirectX 时指定不支持的 MSAA 会崩溃
* Windows 版移动到 DPI 不同的显示器时缩放异常
* 项目以相对路径保存，但设置中指定了绝对路径
* 相机放大或缩小后变形的变形状态被重置
* 向回定位时材质变形被重置
* 从远离相机原点位置重置时，模型边缘显示异常粗
* 在未打开效果设置画面的状态下分配效果文件时崩溃

  * 改为显示指示打开效果设置画面的错误

* 非透视时相机计算错误，导致选择非透视时看起来什么都没绘制
* 使用 ``shared`` 关键字的效果中，离屏内绘制对象在部分情况下不绘制

  * 具体在 `msToonCoordinator <https://note.com/mashimashi_note/n/na1bc7c72e511>`_ 中问题明显

* 模型加载时，纹理所在文件夹在模型文件夹外侧时显示为白色
* 项目保存时若未选择模型，加载时未选中状态不反映
* Windows 版错误显示中可能发生乱码
* 使用 ``Post_ScreenTex.fx`` 时绘制不正确
* 加载相机运动时角度错误（X 轴反转）

  * 32.0 之前保存的项目在加载时自动修正
  * 以相机运动导出并加载时不修正，请重新从原项目导出

* 项目加载失败时及效果的内存泄漏问题
* 24bit 音源加载时不显示波形
* 背景视频包含音源时可能无法正确解码
* 使用效果时背景视频可能无法正确显示
* Windows 版在带有背景视频保存项目后加载时，背景视频不显示
* Windows 版图像或视频导出时，项目有变更时不显示保存确认对话框

32.0.0 (2021/3/8)
******************************************

功能添加
==========================================

* 实验性支持软体

规格变更
==========================================

* 停止在 nanoem 应用中使用 Google Analytics (Google Measurement Protocol)

  * 详见 :doc:`privacy`
  * 继续使用 Sentry 的崩溃报告功能

缺陷修复
==========================================

* 图像或视频导出时，包含后期效果且启用抗锯齿执行时可能崩溃
* 抗锯齿设置后，效果的 RENDERCOLORTARGET 语义纹理未应用抗锯齿

  * 图像或视频导出时即使启用抗锯齿，也未能对后期效果应用抗锯齿
  * 离屏纹理由效果侧控制，不受影响

* 图像或视频导出时出现的对话框取消一次，再次执行后点击取消时对话框双重出现可能导致崩溃
* macOS 版使用 Metal 时勾选「启用 OS 自带编码器」导出会生成全黑视频
* Windows 版菜单的访问键（助记符）不能正常工作
* Windows 版文件保存时扩展名有时会重复

.. [#f1] 当 GPU 无法使用时，由于添加了使用 `WARP <https://docs.microsoft.com/en-us/windows/win32/direct3darticles/directx-warp>`_ 的处理，原则上不会发生

时间轴

.. image:: images/application/timeline.png

（调整大小）
==========================================

.. note::
    此功能从 26.4 引入

将鼠标悬停在时间轴与 :ref:`D00A9E0D-8AE1-4E1A-A8BC-C85CBAE1C537` 之间时，会显示绿色条。
拖动此绿条可以调整时间轴的大小，:ref:`D00A9E0D-8AE1-4E1A-A8BC-C85CBAE1C537` 也会随之缩放。

初始值调整为时间轴与 :ref:`D00A9E0D-8AE1-4E1A-A8BC-C85CBAE1C537` 的比例为 30:70，可在 25:75 到 75:25 之间调整。
当调整到接近 30:70 的比例时，会自动吸附到 30:70。

.. caution::
   - 已知问题：多次调整大小时，:ref:`D00A9E0D-8AE1-4E1A-A8BC-C85CBAE1C537` 会逐渐变小

    - 此时请从「视口设置对话框」中先更改分辨率值，再改回原值
    - 缩放窗口无效，请使用上述方法处理

   - 没有禁用吸附的功能

（帧移动）
==========================================

移动当前帧位置

.. important::
  - 「帧」与「关键帧」是不同的！

    - 具体来说，关键帧在时间轴上显示为 🔶 标记
    - 选中的关键帧 🔶 标记变为橙色

- 点击右方向按钮移动到前一帧

  - 例如当前帧位置为 123 时，按下后移动到 124

- 点击 ⏩ 双右方向按钮移动到前方向存在关键帧的帧

  - 例如当前帧位置为 123，下一个关键帧在 115 时，移动到 115
  - 主要用于相机运动的关键帧移动

- 点击左方向按钮移动到后一帧

  - 例如当前帧位置为 123 时，按下后移动到 122

- 点击 ⏪ 双左方向按钮移动到后方向存在关键帧的帧

  - 例如当前帧位置为 123，下一个关键帧在 130 时，移动到 130

- 按钮可以长按

  - 长按可以快速移动

- 可以直接输入数值，按回车键移动到该位置

（时间轴内的范围拖动）
==========================================

- 可以在时间轴内拖动

  - 拖动时从开始位置到结束位置显示红色矩形
  - 红色矩形中包含的关键帧将被选中

（关键帧拖动）
==========================================

.. note::
    此功能从 25.0.0 引入

- 选中关键帧后拖动可以移动选中的关键帧

  - 如果移动目标已存在关键帧，则会以覆盖方式删除原有关键帧

扩展
==========================================

.. caution::
    相机不支持此功能，因为相机将相邻关键帧用作场景切换（MikuMikuDance 也因同样原因不支持）。请改为手动偏移相机的关键帧。

将上述「开始」和「结束」范围内的所有关键帧的帧时间以 0.1-10 倍进行缩放。

  * 放大时，处理的部分会像慢动作一样播放
  * 缩小时，处理的部分会像快进一样播放
  * 选择范围之后的所有关键帧会自动移动缩放对应的帧时间

适用于相机以外的运动。对于模型，是对选中的模型执行，因此要应用到所有模型，请逐个选择模型重复执行缩放操作。

手柄
==========================================

用于操作模型和相机，由 :ref:`D00A9E0D-8AE1-4E1A-A8BC-C85CBAE1C537` 画面右下角的六个圆形按钮及其上方的按钮组成。

- 通过拖动可以移动或旋转模型或相机

  - 红色代表 X 轴、绿色代表 Y 轴、蓝色代表 Z 轴
  - 四方向箭头的图标为「移动」，两个箭头旋转显示的图标为「旋转」

- 点击显示 ``Global`` 或 ``Local`` 的部分可以更改变形基准

  - ``Global`` 沿 XYZ 轴进行旋转变形
  - ``Local`` 基本与 ``Global`` 相同，但当设置了「局部轴」时沿该轴进行变形

插值曲线面板
******************************************

.. important::
    34.0 及之前显示为「补完」，这是「补间」的错误写法。

.. note::
    插值曲线面板仅在关键帧为骨骼或相机时生效。

插值曲线用于设置关键帧与关键帧之间的动作变化。插值曲线的优点：

- 比逐帧设置参数并注册关键帧高效得多

  - 之后需要调整动作时只需调整插值曲线的参数

    - 逐帧注册关键帧时，需要修正所有受影响的关键帧，非常耗时

- 可以减少关键帧数量，从而减小运动文件体积

但对于动作变化较大的情况，插值曲线难以控制，因此显式设置参数并注册关键帧可能更有利。

插值曲线的设置步骤
==========================================

.. caution::
    仅设置图形或参数不会反映到关键帧。务必通过「注册」来注册关键帧。

插值曲线的设置需按以下步骤进行：

* 选择「**仅一个**」关键帧

  * 选择多个时不会显示红点，无法设置
  * 插值曲线的设置对象是「**不是前一个关键帧，而是下一个关键帧**」

    * 例如，如果插值曲线的设置对象起始在第 3 帧、下一个在第 10 帧，则选择第 10 帧的关键帧

* 点击齿轮图标
* 显示插值曲线图后，拖动其中的红点

  * 常用 S 型曲线：将左下方的红点移到下中央，右上方的红点移到上中央即可实现

* 按 OK，相机则点击「:ref:`F9271EEB-8C28-4EA6-B23A-0409689A8610`」的「注册」，骨骼则点击「:ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7`」的「注册」来注册关键帧
* 根据需要，通过「:ref:`8DF11AFA-D8D1-4A15-B8E7-B9BBB246C7FD`」进行设置后播放确认动作

插值曲线图面板
==========================================

.. caution::
   * 用于显示的齿轮图标需要选择一个以上关键帧才会生效

     * 骨骼的情况下，如果忘记选择关键帧而仅选择了骨骼，按钮会保持禁用状态

   * 再次强调，按 OK 并不等于注册了关键帧。务必通过「注册」按钮注册。

点击齿轮图标，会显示针对所选的所有骨骼或相机关键帧的插值曲线面板。

- 如果选中的关键帧设置了不同的插值曲线，会以重叠方式绘制

  - 「线性插值」顾名思义，是从左下到右上的斜向直线
  - X 轴为时间，Y 轴为关键帧之间的参数比率

    - X 轴左侧为前一关键帧，右侧为下一关键帧
    - Y 轴下方为前一关键帧，上方为下一关键帧

- 如果未选择任何关键帧，则不会绘制
- 从 1.19 开始，显示绿色圆点标记，可以了解当前帧位置在插值曲线上的位置

更改插值曲线
------------------------------------------

.. important::
    仅当「只选择了一个关键帧」时才能更改插值曲线。
    选择了多个关键帧时会显示，但无法批量编辑。

通过拖动两个圆点可以更改插值曲线。
插值曲线内部使用贝塞尔曲线，因此点不一定穿过曲线。

- 更改对象为骨骼时，需要通过「:ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7`」的「注册」按钮来反映
- 更改对象为相机时，需要通过「:ref:`F9271EEB-8C28-4EA6-B23A-0409689A8610`」的「注册」按钮来反映

复制
==========================================

.. caution::
    与时间轴或「:ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7`」中的「复制」功能独立，不能共享

复制选中关键帧的插值曲线。

粘贴
==========================================

.. caution::
    与时间轴或「:ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7`」中的「复制」功能独立，不能共享

将通过「:ref:`81AE5045-96FB-4E96-92F9-0EC91FD5B4FD`」复制的插值曲线粘贴到当前选中的关键帧。

线性插值
==========================================

将当前选中的关键帧的插值曲线全部设置为线性插值。线性插值是关键帧注册时的初始值，因此实际上也可作为插值曲线的重置。

自动插值
==========================================

勾选「自动插值」时，注册关键帧时还会进行以下设置。这些仅针对「骨骼移动」执行，不针对骨骼旋转或相机。

* 如果「注册目标的前一个关键帧」为线性插值，则重新设置为 S 型曲线
* 如果注册目标为中间关键帧，则根据前后关键帧的差值计算比例，按该比例分割插值曲线

自身阴影面板
==========================================

打开自身阴影面板。可以设置以下内容：

模式
------------------------------------------

距离
------------------------------------------

设置自身阴影的覆盖距离。更改距离后的行为因模式而异：

- 模式 1（平衡型）

  - 设小：靠近相机的物体的自身阴影更精细

    - 但远处的自身阴影会被裁剪

  - 设大：远离相机的物体的自身阴影会被覆盖

    - 但靠近相机的物体的自身阴影会变粗糙

- 模式 2（近距离优先）

崩溃后的项目恢复
==========================================

nanoem 崩溃后启动时，会显示恢复确认画面。
点击 OK 将根据崩溃前的操作内容进行恢复。

其机制是在「帮助」中添加了 `Open Redo Log Directory`，
将操作内容逐条写入打开的文件夹，崩溃时读取该文件来实现恢复。
每次创建项目时都会生成，如不需要请随时删除。

.. danger::
    如果移动了加载的附件、模型、运动的源文件，将无法正确恢复，因此请不要移动已加载的文件。

以下操作内容可恢复：

* 附件的加载
* 模型的加载
* 运动的加载
* 关键帧注册及删除

  * 配件
  * 骨骼
  * 形态
  * 相机
  * 光源

* 骨骼变形
* 形态变形

上述以外的操作，例如配件的透明度或缩放比例设置，不属于恢复对象，请先注册到关键帧。

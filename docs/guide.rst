=============================================================
快捷使用指南
=============================================================

根据使用目的说明相应的方法。

总之先该做什么？
*************************************************************

.. hint::
   基本操作方法建议观看「`自己试着做了个让3D初音跳舞的工具（说明前篇） <https://www.nicovideo.jp/watch/sm2420025>`_」和「`自己试着做了个让3D初音跳舞的工具（说明后篇） <https://www.nicovideo.jp/watch/sm2420128>`_」。
   虽然是2008年的视频，UI 与现在有所不同，但基本操作方法没有变化。

最简单的方法是加载模型和对应的运动数据，然后播放。根据需要加载配件。

寻找模型
=============================================================

在 `Niconico动画 <http://www.nicovideo.jp/video_top>`_、`Niconico静画 <http://seiga.nicovideo.jp/>`_、`Niconi立体 <http://3d.nicovideo.jp>`_ 中搜索「`MMDモデル配布あり <http://www.nicovideo.jp/tag/MMD%E3%83%A2%E3%83%87%E3%83%AB%E9%85%8D%E5%B8%83%E3%81%82%E3%82%8A>`_」标签可以找到大量各种模型。
在 Twitter 上搜索「`MMDモデル配布あり` 的标签 <https://twitter.com/hashtag/MMD%E3%83%A2%E3%83%87%E3%83%AB%E9%85%8D%E5%B8%83%E3%81%82%E3%82%8A>`_」也可能会找到。

如果太多无法选择，可以使用 Niconi立体 分发的 `Alicia Solid <http://3d.nicovideo.jp/alicia/>`_ 模型。

.. caution::
    分发的模型通常附带有兼具使用说明和用户协议的 README 或类似文件，使用时请务必阅读。

.. tip::
    nanoem 内置了查看上述文本文件的功能。

寻找让模型跳舞用的运动数据
=============================================================

在 `Niconico动画 <http://www.nicovideo.jp/video_top>`_、`Niconico静画 <http://seiga.nicovideo.jp/>`_、`Niconi立体 <http://3d.nicovideo.jp>`_ 中搜索「`MMDモーション配布あり <http://www.nicovideo.jp/tag/MMD%E3%83%A2%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E9%85%8D%E5%B8%83%E3%81%82%E3%82%8A>`_」标签，可以找到与模型一样各种各样的运动数据。
在 Twitter 上搜索「`MMDモーション配布あり` 的标签 <https://twitter.com/hashtag/MMD%E3%83%A2%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E9%85%8D%E5%B8%83%E3%81%82%E3%82%8A>`_」也可能会找到。

- 运动数据通常配合乐曲一起分发，因此确定了基础乐曲就更容易筛选
- 除了跳舞用的运动外，有时还会单独分发口型（口パク）专用的运动

.. caution::
    分发的运动与模型一样，附带有兼具使用说明和用户协议的 README 或类似文件，使用时请务必阅读。

.. tip::
    nanoem 内置了查看上述文本文件的功能。

寻找配件
=============================================================

在 `Niconico动画 <http://www.nicovideo.jp/video_top>`_、`Niconico静画 <http://seiga.nicovideo.jp/>`_、`Niconi立体 <http://3d.nicovideo.jp>`_ 中搜索「`MMDアクセサリ配布あり <http://www.nicovideo.jp/tag/MMD%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B5%E3%83%AA%E9%85%8D%E5%B8%83%E3%81%82%E3%82%8A>`_」标签，可以找到与模型一样各种各样的配件。
在 Twitter 上搜索「`MMDアクセサリ配布あり` 的标签 <https://twitter.com/hashtag/MMD%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B5%E3%83%AA%E9%85%8D%E5%B8%83%E3%81%82%E3%82%8A>`_」也可能会找到。

- 搜索「`MMDステージ配布あり <http://www.nicovideo.jp/tag/MMD%E3%82%B9%E3%83%86%E3%83%BC%E3%82%B8%E9%85%8D%E5%B8%83%E3%81%82%E3%82%8A>`_」标签，可以找到作为背景及舞台的配件或模型。
- 搜索「`MMDスカイドーム配布あり <http://www.nicovideo.jp/tag/%E3%82%B9%E3%82%AB%E3%82%A4%E3%83%89%E3%83%BC%E3%83%A0>`_」标签，可以找到作为天空背景的配件或模型。

.. note::
    天空穹顶通常制作成足够大、覆盖舞台的球状模型，并贴有天空纹理。将相机拉远即可确认。

寻找相机运动
=============================================================

搜索「`#MMDカメラモーション配布あり <http://www.nicovideo.jp/tag/MMD%E3%82%AB%E3%83%A1%E3%83%A9%E3%83%A2%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E9%85%8D%E5%B8%83%E3%81%82%E3%82%8A>`_」即可找到。相机运动有时会与模型跳舞用的运动一起分发，但通常单独分发。

相机运动的加载方法与模型（的运动）相同，只是选择相机而非模型。

想要加载模型或配件
*************************************************************

.. important::
    模型或配件通常以 zip 格式分发，首先需要解压。

    此时如果在 macOS 上 `按常规方法解压 <https://support.apple.com/zh-cn/guide/mac-help/mchlp2528/mac>`_，文件名可能会出现乱码，导致加载模型或配件时一部分或整体显示为白色的问题（:ref:`1A68F001-C7E3-41FD-A1AC-0D84505D38DC`）。

    为避免此问题，需要使用专用的解压应用程序。详情请确认「:ref:`0C54A757-1FA3-4CC9-B33E-E9362B69A25B`」。

- 模型可以加载扩展名为 ``PMD`` 或 ``PMX`` 格式的文件。
- 配件可以加载扩展名为 ``X`` 格式的文件。

  - 配件的方法相同，只是不会显示使用确认对话框。

方法 1
=============================================================

详情请参考「:ref:`3F20FD13-9F9B-49FD-9072-0DE3FE50CE58`」及「:ref:`14C11FDE-A0FC-4415-A408-383B0132F735`」

#. 选择菜单的「文件」>「打开」>「模型」（配件请选择「文件」>「打开」>「配件」）
#. 显示对话框后，选择要加载的模型或配件文件
#. 显示使用确认对话框，确认内容后点击「OK」

方法 2
=============================================================

#. 拖动要加载的模型文件
#. 放到 nanoem 窗口上
#. 显示使用确认对话框，确认内容后点击「OK」

方法 3
=============================================================

#. 点击「模型」或「配件」面板的「读取」按钮
#. 显示对话框后，选择要加载的模型或配件文件
#. 显示使用确认对话框，确认内容后点击「OK」

想要加载运动或姿态
*************************************************************

运动可以加载 MMD 使用的 ``VMD`` 格式或 nanoem 独有的 ``NMD`` 格式。

姿态可以加载 MMD 使用的 ``VPD`` 格式。同时支持包含形态信息的扩展格式。

.. caution::
  - 加载运动时请将帧位置设为 0（当前帧位置会被视为起始点）
  - ``NMD`` 是 nanoem 独有的扩展运动格式，MMD 或兼容类应用程序无法加载

模型（含姿态）
=============================================================

模型的运动或姿态需要预先选择要加载的模型，然后进行加载。刚加载模型后，该模型即为选中状态。

方法 1
-------------------------------------------------------

详情请参考「:ref:`13C2505E-631B-4885-86DA-1AEAFF56BAB9`」

#. 从菜单的「项目」>「选择」>「模型」中选择要应用运动的模型
#. 选择菜单的「文件」>「打开」>「运动」>「模型运动」（姿态请选择菜单的「文件」>「打开」>「姿态」）
#. 显示对话框后，选择要加载的运动或姿态文件

方法 2
-------------------------------------------------------

#. 预先选择要加载运动的模型
#. 拖动要加载的运动或姿态文件
#. 放到 nanoem 窗口上

想要移动模型
*************************************************************

.. hint::
   这里仅说明基本操作方法。涉及运动创作的进阶内容，建议查看标有「`MMDモーション講座 <https://www.nicovideo.jp/tag/MMD%E3%83%A2%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E8%AC%9B%E5%BA%A7>`_」或
   「`MMDトレース講座 <https://www.nicovideo.jp/tag/MMD%E3%83%88%E3%83%AC%E3%83%BC%E3%82%B9%E8%AC%9B%E5%BA%A7>`_」标签的视频。

移动前需要先选择模型。首先介绍模型的选择方法：

选择模型
=============================================================

方法 1
-------------------------------------------------------

#. 选择菜单的「项目」>「选择」>「模型」
#. 点击模型名称

方法 2
-------------------------------------------------------

#. 点击「模型」面板的「默认」
#. 点击模型名称

选择要移动的模型后，确定要移动的对象。模型可以通过「骨骼」和「形态」两个元素来添加动作。
静止状态作为姿态，多个不同姿态形成动作的就是运动。

通过移动骨骼可以使模型做出灵活的动作，但如果不理解其特性可能会产生意外动作，
因此初学者最好先通过滑块即可确认效果的形态来练习。

移动骨骼
=============================================================

分为「选择骨骼」「操作骨骼手柄」「复制及粘贴骨骼」

.. _CB9F0F8C-6DEC-4B5B-ABBE-9699A710E7AC:

选择骨骼
-------------------------------------------------------

.. caution::
    选择时间轴上的 🔶 关键帧并不等于选择了骨骼。

可以通过以下任一方法选择骨骼。选择后图标会显示为红色。

- 点击模型上的圆形或方形图标
- 点击时间轴上显示骨骼名称的部分
- 从「模型」>「选择骨骼」中点击骨骼名称

如需批量选择，请使用 :ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7` 的「:ref:`18D9F87A-2AA7-441B-8BAA-4CC50B567B26`」。

- 点击「框选」
- 拖动以指定范围

移动骨骼
-------------------------------------------------------

骨骼是移动模型的重要元素之一。移动骨骼可以使用以下两种方法：

- 点击「骨骼」面板的「旋转」或「移动」按钮显示的手柄

  - 「:ref:`A6163404-A26F-4AC3-86FF-689CC6F857E4`」按钮显示的手柄以红、绿、蓝三色区分（黄色是中心点，不可操作）

    .. csv-table::

       **对象**,**效果**
       纵轴红色,X 轴方向移动
       圆周外围绿色,Y 轴方向移动
       横轴蓝色,Z 轴方向移动

  - 「:ref:`F3CCBD2A-75D2-47E1-805C-31D0F0B6FE3A`」按钮显示的手柄以红、绿、黄三色区分

    .. csv-table::

       **对象**,**效果**
       横轴红色,「从相机视角看」X 轴方向移动
       纵轴绿色,「从相机视角看」Y 轴方向移动
       圆形黄色,「从相机视角看」任意方向移动

- :ref:`D00A9E0D-8AE1-4E1A-A8BC-C85CBAE1C537` 画面右下排列的 X/Y/Z 图标

  - 有上下左右箭头的图标是移动骨骼的手柄
  - 旋转中的图标是旋转骨骼的手柄
  - 两者均可通过拖动上下方向来操作

    - 注意不能左右移动

.. hint::
    移动骨骼后，图标的颜色会从蓝色变为绿色。在此状态下点击「:ref:`E28819DE-98C7-4509-8EF7-865A7D2D9799`」按钮，该骨骼会自动被选中。

操作完成后，点击「骨骼」面板的「注册」即可注册到关键帧。

复制及粘贴骨骼
-------------------------------------------------------

.. caution::
    :ref:`721C4B9C-55DD-46BD-A506-DA412489831E` 中的「复制」和「粘贴」是独立于关键帧的功能，按下不会生效。
    另外，使用菜单「编辑」中的「复制」或「粘贴」时，需要处于 :ref:`BE2EE075-599C-4F58-A87D-15665E8DE8BA` 状态。

.. note::
    粘贴时可以应用于不同的模型，但此时骨骼名称必须一致。

#. 通过「:ref:`CB9F0F8C-6DEC-4B5B-ABBE-9699A710E7AC`」的方法选择骨骼
#. 通过菜单的「编辑」>「复制」或 :ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7` 中的「:ref:`B2B4FD27-866F-459C-AC92-F6DF01319F73`」进行复制
#. 移动到要粘贴的目标帧位置
#. 通过菜单的「编辑」>「粘贴」或 :ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7` 中的「:ref:`31726C83-C320-417C-975A-C490ADC99635`」进行粘贴

移动形态
=============================================================

形态是与骨骼并列的模型移动元素之一，分为以下类别：

.. csv-table::

   **类别名称**,**说明**,**示例**
   唇,主要控制口部动作,あ、い、う
   目,主要控制眼部动作,眨眼、wink
   眉,主要控制眉毛动作,认真、困扰
   其他,不属于以上任何类别,瞳孔小

.. caution::
    每个类别都有各自的注册按钮，但处理是独立的。例如，移动「目」类别的形态后按下「其他」类别的注册按钮，注册的不是「目」类别，而是「其他」类别中选择的形态。

.. hint::
    点击左右按钮可以在 0.0 到 1.0 之间以 0.01 为单位调整。双击数值部分可以直接输入数值。

#. 加载并选择要移动形态的模型
#. 从「:ref:`D971D5DE-F7A7-4643-9A97-AFB7A8495649`」拖动形态名称下方的「权重」或「权重」与数值的空白区域左右拖动
#. 调整完形态值后点击「注册」注册关键帧
#. 重复步骤 1

想要复制粘贴运动的关键帧
*************************************************************

.. hint::
    要纵向选择所有关键帧，请按下「:ref:`181F003D-42A0-4E7F-B92A-3143C39DFBC5`」。

    要横向批量选择关键帧，请按下 :ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7` 中的「:ref:`624222B5-6FD8-4565-855F-18B01543E52B`」。
    可以通过 From 和 To 设置选择范围，左侧下拉菜单可以选择全选或仅选择特定骨骼或形态。

.. caution::
    :ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7` 中的「复制」和「粘贴」是独立于骨骼的功能，按下不会生效。
    另外，使用菜单「编辑」中的「复制」或「粘贴」时，需要处于 :ref:`BE2EE075-599C-4F58-A87D-15665E8DE8BA` **以外** 的状态。

#. 选择标记或在 :ref:`721C4B9C-55DD-46BD-A506-DA412489831E` 上拖动选择关键帧
#. 通过菜单的「编辑」>「复制」或 :ref:`721C4B9C-55DD-46BD-A506-DA412489831E` 中的「:ref:`61D8222D-2A1D-4DC5-A960-0586D153F05A`」进行复制
#. 移动到要粘贴的目标帧位置
#. 通过菜单的「编辑」>「粘贴」或 :ref:`721C4B9C-55DD-46BD-A506-DA412489831E` 中的「:ref:`FBD923A1-046B-4087-A094-D9D0F592F754`」进行粘贴

想要加载音频
*************************************************************

.. note::
    如果无法正常加载，请确认「:ref:`2956D851-EA68-4AA6-8A91-396A8B74AF44`」。

要清除音频，可以通过菜单的「项目」>「清除音频」实现。此时播放时间会自动调整。

想要加载背景视频
*************************************************************

按以下步骤操作。重新加载其他背景视频时，会替换之前的视频。

#. 点击菜单的「文件」>「打开」>「背景视频」
#. 点击要加载的背景视频文件

.. hint::
    按住 Shift 键拖动画面右上角的相机图标，可以缩放和移动背景视频的位置。
    这主要用于运动追踪功能。

详情请参考「:ref:`4BF77CBD-F154-479A-8CC6-83F19677CB04`」。

想要清除背景视频
=============================================================

要清除背景视频，可以通过菜单的「项目」>「清除背景视频」实现。

想要播放
*************************************************************

点击 :ref:`8DF11AFA-D8D1-4A15-B8E7-B9BBB246C7FD` 的「播放」按钮即可播放。

也可以通过菜单的「项目」>「播放」来播放。

循环播放及范围播放
=============================================================

想要循环播放，可以勾选「播放」面板的「循环」。循环播放即可。
另外，要指定帧范围，请在「开始」和「结束」中分别指定帧位置，并勾选左侧的复选框。

想要加载效果
*************************************************************

效果与模型或附件同时加载并应用。方法请参考「:ref:`D0A41A9C-E3AF-499E-BC17-1EABC1A66744`」。扩展名为 FX 或 FXN 格式的文件可以加载。

.. note::
  从 1.14.0.0 开始，加载效果时如果效果插件未启用，会显示确认对话框。

  - 点击 ``OK`` 按钮会启用效果插件，同时自动加载效果。
  - 点击 ``Cancel`` 按钮会取消加载。

  从 1.12.0.0 开始，扩展名为 ``FX`` 的文件也可以加载。

  - 原则上可以直接加载 MME 的效果。
  - 有时可能无法加载或显示不正确。
  - 通过名为效果插件的机制加载，默认为禁用。

希望将配件或模型附加到特定模型上（外部父级）
*************************************************************

将配件或模型附加到特定模型的功能称为外部父级。利用此功能，例如可以让特定模型持有武器。

让模型持有配件
=============================================================

.. note::
    配件与模型只能按 1:1 附加。例如，想要让配件同时持于特定模型的双手中时，请使用虚拟模型，通过其包含的骨骼作为连接目标。

    虚拟模型包含在 MikuMikuDance 的附带文件中，nanoem 也可以通过勾选「:ref:`F517A3B9-3273-4FE3-BD1E-4EDA53843140`」后，从出现的「:ref:`EEE59B7A-FB14-48E3-B63F-D39AF815CE51`」添加骨骼来实现。

#. 切换到相机画面（不选择模型的状态）
#. 从 :ref:`BBE442C0-390F-4E8C-8095-F4BB138FD2C5` 选择要让其持有的配件
#. 按下 :ref:`CE92F96B-DB6C-483C-B698-8781ACE017C4` 的按钮
#. 设置「连接目标父模型」和「连接目标骨骼」

让模型持有模型
=============================================================

与配件不同，需要额外设置目标骨骼，但一个模型可以将多个骨骼作为外部父级连接。
也就是说，配件需要多个连接目标时需要分别加载，而模型可以合并为一个。

#. 选择要持有的目标模型
#. 按下 :ref:`E6F3DE0F-97F9-4515-ABC0-58B8999A9E70` 中的 :ref:`7A2F7651-1FF4-4669-861B-3A687D468E31` 按钮
#. 设置「目标骨骼」「连接目标父模型」和「连接目标骨骼」
#. 按下「外部父级注册」

想要更改物理模拟设置
*************************************************************

可以通过「项目」>「物理模拟」>「运算设置」进行设置。详情请参考「:ref:`F3B3AAC8-0D8C-4409-8439-8764F37F2962`」。

想要禁用 IK/物理模拟
*************************************************************

IK 及物理模拟有助于简化操作和提升动作的真实性，但由于其复杂性，有时会产生意想不到的动作。
此时有时需要特意禁用 IK 或物理模拟，手动调整动作。

这里说明禁用 IK 或物理模拟的方法。

禁用 IK
=============================================================

按以下步骤可以禁用 IK。

#. 移动到要禁用的帧位置
#. 从 :ref:`E6F3DE0F-97F9-4515-ABC0-58B8999A9E70` 的「外」按钮左侧列表中选择要禁用的 IK 目标
#. 点击其下方的 ON/OFF 中的 OFF
#. 点击下方的「注册」

一旦禁用，直到下一个模型的关键帧生效前将保持禁用状态。

.. _166E84B9-236D-41F4-9FD0-CCA457D28076:

按骨骼禁用物理模拟
=============================================================

.. caution::
    :ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7` 的「物理」复选框是在注册关键帧时使用的，不反映当前位置关键帧的物理启用/禁用状态。请确认时间轴上的标记。

按以下步骤可以按骨骼禁用物理模拟。

#. 移动到要禁用的帧位置
#. 选择要禁用的骨骼
#. 取消勾选 :ref:`54B1F974-2B39-4472-B6F5-EAB40FDCC4F7` 中的「物理」
#. 点击下方的「注册」

如果时间轴上的标记从 ❌ 变为 🔶，则表示已成功禁用。由于特性上存在复杂规格，详情请参考「:ref:`4EDF4607-B9B0-4E2D-A347-3701E240E1EC`」。

想要添加半标准骨骼
*************************************************************

.. note::
    分发的模型除非是相当旧的版本，否则通常已预先包含半标准骨骼。但对于自制模型或从 `VRoid Studio <https://vroid.com/studio>`_ 转换的模型等可能没有，需要时需执行添加。

首先确认 :doc:`plugin` 后，安装「:ref:`CCDE11E1-3416-425D-80DF-A347F79E7BDD`」。请注意与 PMDEditor/PMXEditor 的版本不兼容，即使添加也不会生效。

选择目标模型后，选择「编辑」>「:ref:`7F24495C-52C6-4659-A309-0E75CAB72D3B`」>「半标准骨骼插件」>「设置与执行」，根据需要设置后点击「OK」。

想要进行运动追踪
*************************************************************

.. warning::
    初学者直接尝试可能非常困难且极易受挫，请至少掌握以下技能后再进行：

   * 能够加载模型
   * 能够加载运动
   * 能够移动相机
   * 能够移动骨骼
   * 能够移动形态
   * 理解背景视频的加载和移动方法
   * 能够制作姿态
   * 能够复制粘贴关键帧
   * 能够使用「:ref:`CCDE11E1-3416-425D-80DF-A347F79E7BDD`」

    此外，运动追踪源的「踊ってみた」类编舞可能产生著作权 [#f1]_ [#f2]_，对外公开时请事先取得运动追踪源许可。

基本操作：加载背景视频，让模型配合背景视频制作姿态，然后移动到下一帧继续制作姿态...如此反复。虽然有明确的终点，但这是一项需要大量时间和耐心的作业（熟练后可以缩短作业时间）。

也可以选择不直接在 nanoem 中加载背景视频，而是在视频播放器中加载作为参考视频使用，哪种方法最佳因人而异。

关于方法论，请搜索「`#MMDモーション講座 <https://www.nicovideo.jp/tag/MMD%E3%83%A2%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E8%AC%9B%E5%BA%A7>`_」或「`#MMDトレース講座 <https://www.nicovideo.jp/tag/MMD%E3%83%88%E3%83%AC%E3%83%BC%E3%82%B9%E8%AC%9B%E5%BA%A7>`_」标签。
